# 2026-07-17 Agent 市场页面重设计

## 当前目标

用户要求把旧版 Agent 市场页面也重新设计，使其与已整理的导航和工作区结构一致，同时保留现有 Agent 调用、健康诊断、管理员操作与出域确认能力。

## 本次完成

- 将页面重构为“市场概览 + 可搜索 Agent 目录 + 聚焦工作台”。
- 新增全部、本地、外部筛选，目录中展示来源、健康状态、ID 与主要能力。
- 将运行状态、熔断、连接、能力、试调和市场管理分层展示，原始诊断与完整响应改为渐进披露。
- 外部 Agent 继续要求确认出域发送；授权、安装、停用仍只对管理员开放。
- 新增页面专属响应式样式，覆盖桌面、平板、手机和减少动态效果场景。
- 增加组件测试与端到端断言，并修正健康数据缺失时误计为正常的边界。
