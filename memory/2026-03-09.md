## 追加更新（2026-03-09 / 文本框结构安全拆段）
- `ensureDocxLogicalParagraphsBuffer` 现在对 `w:txbxContent` 不再直接跳过。
- 新实现采用：
  - 先把 `<w:txbxContent>...</w:txbxContent>` 用内部 token 抽离
  - 正文层面先处理不含 textbox 内段落的 XML
  - 再单独处理 textbox inner XML
  - 最后 restore 回原始位置
- 这样可以避免“外层段落 + textbox 内层段落”形成嵌套 `<w:p>` 时，把段落 regex 匹配串掉。
- 结果是 `w:txbxContent` 里的多行正文占位符现在也能拆段，并复用现有标题提升规则。
