## 可沉淀为长期记忆

- 远程 renderer 不能自报本地存储用户身份；应由服务端签发短时、限定 audience 的绑定 token，native 只向编译期固定 HTTPS 服务验证。
- 模型 API Key 的钥匙串 account 必须与设备加密 key 分命名空间；跨 origin 更新必须先成功写密钥，再提交 profile，失败回滚。
- 非交互 macOS DMG 构建需跳过 Finder AppleScript 美化；交互终端可保留布局，CI/代理环境应自动设置 `CI=true`。
- GitHub HTTPS PAT 推送新增或修改 workflow 文件时必须具有 `workflow` scope；普通仓库写权限不足。
- 版本规则：大改升主版本、功能优化升次版本、Bug 修复升修订版本；正常 Conventional Commit 由 Git hook 自动升版、改提交标题并推送。
