## 可沉淀为长期记忆

聚信 AI 助手桌面端 Agent 使用独立语义化版本，不随服务端版本同步。版本规则：大改升第一位，功能优化升第二位，Bug 修复升第三位；自动升级包、Git 提交和推送版本必须对应。

Prompt 生产发布必须避免半发布窗口：在 Prompt Center 激活成功前，现有任务继续使用旧 published 绑定，新任务不可见；激活后再通过独立 rollout 批次表和条件更新原子切换 AI 助手绑定、任务配置、字段和知识。不要依赖 SQLite `FOR UPDATE` 或 `updated_by` 作为状态机 token。

长任务必须持续发送简短进度；上下文接近限制前先更新当日 memory 文件并结束当前批次，不能等待自动压缩失败。
