# SCA V2.0 独立部署与登录改造记忆

## 目标

- 将 SCA 独立成一套可单独启动的系统。
- 品牌改为“九章软件开源组件分析系统”，版本目标为 V2.0。
- 提供 SCA 专属登录入口；身份、会话和权限优先复用统一登录系统，避免复制用户体系。
- 按仓库约定自动升级版本、提交并推送 Git。

## 已确认现状

- `sca-platform/` 已有独立 Docker Compose，前端端口为 18089，API 端口为 5191。
- SCA 现在通过 `auth` 的 `/sca-login` 进入，统一门户的 `system=sca` 兼容路径仍保留。
- `sca-platform/VERSION`、前端包版本、后端 `app_version` 和 Compose 运行时版本均已同步为 `2.0.0`。
- 统一登录已支持 `sca` 系统权限、应用入口和授权动作；SCA API 已通过统一登录的 introspect/authorize 形成请求级认证保护。

## 设计决策

- 使用统一登录作为 SCA 的身份中心，在统一登录中增加 SCA 专属登录路径/品牌上下文。
- SCA 前端未登录时跳转 SCA 专属登录入口；登录成功后回到 SCA。
- SCA 后端校验统一登录会话，并根据 SCA 访问权限拒绝未授权请求。
- 保留 `system=sca` 兼容入口，避免破坏现有统一门户和部署配置。
