# 4.1.3 修订版（auth 登录页恢复与版本号展示）

标签：`v4.1.3`
分支：`codex/4.1.3`

## 本次变更

- 修复 `auth` 镜像漏打包 `system-access-display.js` 导致服务启动失败、登录页无法访问的问题
- 登录页新增版本号角标，和独立后台保持一致
- 页面版本、分支、bootstrap 默认目录同步到 `4.1.3`

## 版本判定

- 上一版本：`4.1.2`
- 当前版本：`4.1.3`
- 判定依据：本次属于 Bug 修复与发布口径同步，因此按修订号升级

## 影响范围

- `auth` 服务镜像打包
- `/portal` 登录页展示
- 版本文档与部署脚本默认分支/目录

## 验证建议

- `docker compose ps auth` 显示 `Up`
- `http://127.0.0.1:5180/portal?system=reminder` 可打开
- 登录卡片右上角可看到 `v4.1.3`
