# v5.16.0 发布说明

## 版本类型

- 功能优化：重做提示词管理中心的提示词列表页面。

## 变更内容

- 提示词列表改为部门优先的浏览工作台，先选择部门，再进入分类目录查看提示词。
- 分类目录与提示词表格并排展示，提示词行保留编辑、删除、收藏和复制操作。
- 列表页增加当前用户的收藏提示词区域，便于快速回到常用提示词。
- 同步提示词管理中心、统一登录系统和根项目版本号为 `5.16.0`。

## 验证

- `npm --prefix prompt-center/frontend test`
- `npm --prefix prompt-center/frontend run build`
- `node --test auth/tests/login-page-version.test.js`
