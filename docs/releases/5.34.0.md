# v5.34.0

## 功能优化

- 培训考试系统新增“讲师评价”功能，普通用户学习课程后可提交或更新讲师评价。
- 新增讲师评价数据表，记录总体评分、讲解清晰度、互动、实用性、节奏、答疑质量和文字反馈。
- 管理员/审核员/审计员可查看讲师评价汇总与评价列表。
- 普通用户访问白名单新增讲师评价相关接口。
