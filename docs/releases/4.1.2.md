# 4.1.2 修订版（admin-center 用户表权限列收缩）

标签：`v4.1.2`
分支：`codex/4.1.2`

## 本次变更

- 列表页“可访问系统”列改为摘要展示：默认显示前 2 个系统标签，其余显示为 `+N`
- 补齐 `admin-center` 与 `audit-center` 的中文系统名称映射
- 审计日志系统列统一走中文展示 helper
- 页面版本、分支、bootstrap 默认目录同步到 `4.1.2`

## 版本判定

- 上一版本：`4.1.1`
- 当前版本：`4.1.2`
- 判定依据：本次属于缺陷修复与显示一致性修正，不新增独立功能模块，因此按修订号升级

## 影响范围

- `admin-center` 用户管理列表
- `audit-center` 审计日志系统名称展示
- 版本文档与部署脚本默认分支/目录

## 验证建议

- `sysadmin` 登录后进入 `admin-center`
- 用户列表中“可访问系统”列不再完整展开所有权限标签
- `admin-center` / `audit-center` 在权限展示中不再出现英文 key
