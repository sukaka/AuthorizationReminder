# v5.32.0

## 功能优化

- 发送计划搜索新增联系人匹配能力，可按联系人姓名、手机号、邮箱、企业微信 ID 查找关联计划。
- 发送计划列表与筛选删除共用同一套搜索条件，避免搜索结果和批量操作范围不一致。
- 前端搜索框提示更新为“搜索计划/授权/客户/联系人”。
