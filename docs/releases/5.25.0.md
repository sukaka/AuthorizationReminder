# v5.25.0

## 功能优化

- 提醒系统客户管理、联系人管理、授权管理、发送管理新增“删除筛选结果”和“删除全部”批量删除能力。
- 批量删除按当前筛选条件匹配全部记录执行，不受当前分页限制。
- 发送管理新增计划名称/授权/客户搜索、客户筛选、启停状态筛选，方便配合筛选删除。

## 安全与数据一致性

- 批量删除接口继续受当前账号客户权限范围限制。
- 客户、联系人、授权批量删除会同步清理关联发送计划、提醒记录、发送记录与授权截图文件。

## 验证

- `node --test server/tests/reminder-bulk-delete.test.js`
- `node --check server/index.js`
- `npm --prefix web run build`
