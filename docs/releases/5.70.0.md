# 5.70.0

## 功能优化

- 新增统一大屏展示中心，接入 SCA、培训考试和授权提醒三个系统。
- 交付 12 套双布局大屏模板，集成 Three.js、ECharts、G6、MapLibre、tsParticles 和 Anime.js。
- 新增受限模板编辑、不可变发布版本、播放列表与移动端播放控制。
- 新增统一鉴权、数据适配、缓存、SSE、来源健康状态和故障降级。
- 新增 Ed25519 签名离线资源包、SHA-256 校验、管理员启用/回滚和审计日志。
- 新增本地地图资源与离线资产校验，离线模式不发起第三方请求。
