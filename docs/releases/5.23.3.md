# 5.23.3

## Bug 修复

- 授权到期提醒邮件在未保存自定义模板时，不再退回固定文案“授权即将到期，请及时续约。”，改为使用带变量的默认模板。
- 提醒模板变量支持 `{变量名}` 与 `{{变量名}}` 两种写法。
- 发送配置页明确区分“测试邮箱变量”和正式“提醒模板变量”。

- `node --check server/index.js && node --check server/reminder-content.js`
- `npm --prefix web run build`
