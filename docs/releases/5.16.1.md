# v5.16.1 发布说明

## 版本类型

- Bug 修复：修正提示词列表页面与确认稿不一致的问题。

## 变更内容

- 提示词列表页调整为确认稿中的单一白色工作台布局。
- 部门区改为左侧固定卡片列表，增加部门短标、提示词数量和分类数量。
- 右侧区域改为面包屑、筛选栏、分类目录、提示词表格的一体化浏览区。
- 收藏区调整为工作台底部，并显示当前用户。
- 同步提示词管理中心、统一登录系统和根项目版本号为 `5.16.1`。
