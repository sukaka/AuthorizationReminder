# v5.18.0 发布说明

## 变更内容

- 提示词发布后增加结果弹窗，成功和失败都会给出明确反馈。
- 发布成功后自动切换到提示词列表，并定位到该提示词所属部门与分类。
- 提示词版本记录增加版本对比能力，可查看标题、摘要、内容、标签的版本差异。
- 同步提示词管理中心、统一登录系统和根项目版本号为 `5.18.0`。

## 验证

- `npm --prefix prompt-center/frontend test`
- `npm --prefix prompt-center/frontend run build`
- `node --test auth/tests/login-page-version.test.js`
