# v5.20.0 发布说明

## 变更类型

- 功能优化

## 优化内容

- 收紧提示词管理权限：只有 `admin` 可以维护部门与分类。
- 提示词创建、修改、删除、发布、归档和版本记录只允许对应部门负责人操作。
- 普通用户在提示词列表中仅保留查看与收藏能力。
- 未发布提示词只对对应部门负责人可见，避免 `admin` 或其他角色越权查看部门草稿。

## 验证

- `npm --prefix prompt-center/backend test`
- `npm --prefix prompt-center/frontend test`

## 版本同步

- 同步根项目、统一登录系统、提示词前端和提示词后端版本号为 `5.20.0`。
