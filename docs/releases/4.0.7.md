# 4.0.7 正式版（安全加固与 Tender AI 能力扩展）

发布日期：2026-03-11
标签：`v4.0.7`
提交：`0544803`

## 已完成

- 认证服务安全加固：
  - 补齐 `CSRF` 校验、会话绑定、弱密钥识别、内置账号默认密码轮换判定
  - 新增认证侧单元测试，覆盖密码哈希、会话校验、启动安全检查等关键逻辑
  - `docker-compose.yml` 中鉴权与数据库敏感配置改为环境变量注入

- FAQ 知识库删除治理增强：
  - 分类删除支持批量校验、部分成功返回和强制删除
  - 强制删除时联动回收关联文章，补齐后端测试
  - 前端补充相应的分类删除/回收交互适配

- Tender 系统完成一轮 AI 工作台能力扩展：
  - 新增解析工作台、起草工作台、知识入库、语义检索、评测 KPI、治理与校验规则库等后端模块
  - 补齐草稿结构、章节生成桥接、评分优化、偏离响应、Word 精排等链路测试
  - 前端补充投标流程、解析工作台、起草工作台、知识入库、运营中心、评测 KPI、语义检索等页面能力
  - 补充 Tender AI 任务契约文档，明确 parse / match / generate / validate / export 五类逻辑 contract

- 培训考试系统安全与运营能力增强：
  - 后端新增题库筛选、分类、导入、组卷规则、成绩中心、安全工具等公共能力
  - 前端补齐结果中心与相关页面适配
  - 文档编辑器拆分为独立 `train-exam-onlyoffice`，不再与 FAQ / Tender 共用文档密钥

- 发布配套资料补齐：
  - 新增本轮 Tender、FAQ、Train Exam、Auth 的设计稿、实现计划、审计结果与每日记忆文件
  - 根目录 `.gitignore` 增加 `.tmp_*` 规则，避免临时文件污染发布提交

## 发布注意事项

- 部署 `auth / faq / tender / train-exam` 前，需要先补齐新的环境变量：
  - `MYSQL_ROOT_PASSWORD`
  - `MYSQL_SHARED_APP_PASSWORD`
  - `AUTH_MYSQL_PASSWORD`
  - `CMDB_MYSQL_PASSWORD`
  - `AUTH_JWT_SECRET`
  - `AUTH_AUDIT_SIGNING_KEY`
  - `AUTH_CONFIG_SECRET_KEY`
  - `AUTH_BUILTIN_ACCOUNT_DEFAULT_PASSWORD`
  - `FAQ_MYSQL_PASSWORD`
  - `FAQ_DOC_EDITOR_JWT_SECRET`
  - `TRAIN_EXAM_MYSQL_PASSWORD`
  - `TRAIN_EXAM_AUDIT_SIGNING_KEY`
  - `TRAIN_EXAM_DOC_EDITOR_JWT_SECRET`

- `train-exam-api` 已切换到独立 `train-exam-onlyoffice`，不要再复用 FAQ / Tender 的 `DOC_EDITOR_JWT_SECRET`。
