# 2.1.0-rc1（第3周工单核心能力）

## 已完成
- SLA 看板分组：
  - 即将超时（24小时内）
  - 已超时
- 状态流与审批流：
  - 状态机：`新建(OPEN) -> 受理(ACCEPTED) -> 处理中(IN_PROGRESS) -> 待验证(WAIT_VERIFY) -> 完成(RESOLVED) -> 关闭(CLOSED)`
  - 高风险工单（`P1` 或 `HIGH/CRITICAL`）关闭前必须审批通过
  - 新增审批接口：`POST /api/tickets/:id/approval`
- 协作模型增强：
  - 主负责人 + 协作人 + 观察者
  - 评论支持 `@用户名`
  - 新增通知中心（协作变更、评论@、审批结果）

## 新增接口
- `GET /api/dashboard/sla-groups`
- `POST /api/tickets/:id/approval`
- `GET /api/notifications`
- `PUT /api/notifications/:id/read`
- `PUT /api/notifications/read-all`
