## 发布摘要

本次新增“聚信 AI 助手桌面端”，采用统一 SSO、远程工作台与 Tauri 本地模型桥接。主要交付包括：

- 八类助手、88 个任务、动态表单、收藏、历史、反馈、敏感确认、设备草稿和待同步队列。
- 本地 OpenAI 兼容模型配置，API Key 通过 Tauri 钥匙串边界保存，不进入服务端业务协议。
- 任务、知识、设置、建议、统计和审计治理能力，并复用统一管理中心与提示词中心。
- 输入输出加密、对象级授权、审计脱敏、托盘、单实例、浅色/深色/跟随系统主题。
- Windows x64 与 macOS arm64 构建脚本、Tauri 配置、产物架构及 SHA-256 校验工具和 CI 矩阵。

四阶段源码均已落地，但 Windows x64 安装包、两平台正式签名/公证及真实安装验收仍缺外部证据，因此本版本尚不可正式发布。

## 构建与交付门槛

`.github/workflows/ai-assistant-desktop.yml` 已在本地备份分支配置 `macos-14` 和 `windows-latest` 两个 unsigned bundle job，官方 actions 固定到 commit SHA，并会执行测试、构建、目标架构检查、产物清单与 SHA-256 校验。当前 PAT 缺少 GitHub `workflow` scope，目标分支先交付其余 5.88.0 内容；权限补齐后再单独提交该 workflow。**当前仅能证明配置源码已准备，不能证明 workflow 已成功运行。**

正式发布前必须补齐：

1. Windows 10/11 x64 runner：构建 MSI 和 NSIS EXE，验证 x64 PE、安装、启动、卸载、WebView2 和 Windows Credential Manager。
2. Apple Silicon macOS 正式签名环境：当前 unsigned DMG 已通过纯 arm64、校验和、挂载和启动冒烟；仍需验证 Keychain、`codesign --verify`、Gatekeeper 与公证。
3. 公司签名/公证环境：提供 Windows 代码签名证书、Apple Developer ID 与 notarization 凭据；凭据只通过受保护 CI secret 注入。
4. 真实更新源尚未具备时保持 updater 禁用；若启用，必须提供 HTTPS 更新源、公钥/私钥管理流程，并执行至少 5 分钟网络捕获证明禁用状态无更新请求。
5. 对最终提交执行仓库 secret 扫描，以及 npm、Python、Rust 依赖审计；对例外项记录风险接受人和截止日期。
