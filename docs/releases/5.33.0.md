# v5.33.0

## 功能优化

- 培训考试系统“考生记录”新增综合评价，基于考生历史考试成绩计算综合评分、评级和建议文案。
- 后端考生历史接口新增 `overall_evaluation` 返回值，后续接入课程评价数据后可继续纳入综合评分。
- 前端结果中心考生记录页展示综合评分、综合评级、考试均分率和综合评价。
