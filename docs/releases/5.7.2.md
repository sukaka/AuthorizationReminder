# 5.7.2

## 本次更新

- 修复提醒系统 `api` 与统一登录 `auth` 使用不同 `JWT_SECRET`、`AUDIT_SIGNING_KEY`、`BUILTIN_ACCOUNT_DEFAULT_PASSWORD` 的部署错误
- 现在提醒系统前端通过统一登录回跳后，`/api/auth/me` 可以正确识别统一登录 cookie，不再卡在“统一登录中”
- 同时统一了提醒系统与统一登录的认证相关密钥来源，避免会话验证和内置账号初始化错位

## 部署说明

- 本次涉及提醒系统 `api` 和统一登录 `auth` 的共享认证配置
- 更新代码后需要重建 `api` 和 `auth` 服务
- 若之前邮箱配置已受旧密钥链路影响，重建后仍建议重新保存一次 SMTP 授权码

## 验证建议

- 打开提醒系统，确认不会再停留在“统一登录中”
- 登录统一门户后重新进入提醒系统，确认可以正常载入页面
- 再验证一次测试邮箱发送和导入用户邮件
