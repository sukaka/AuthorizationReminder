# v5.21.0

## 培训考试系统

- 试卷管理新增定时发布能力，可选择发布日期和发布时间。
- 待发布试卷到达计划时间后，会在列表、详情、开始考试和统计入口自动转为已发布。
- 试卷列表新增发布时间列，并显示待发布状态和计划发布时间。
