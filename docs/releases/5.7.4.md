# 5.7.4

## 本次更新

- 修复发送配置页在点击“保存配置”后，测试邮箱、测试短信、测试企业微信仍可能误报“配置已修改但未保存”的问题
- 保存进行中时，测试按钮会明确提示“配置保存中...”，避免把保存中的状态误判成未保存
- 保存完成后，发送配置页会按最新状态放行测试操作

## 部署说明

- 本次仅涉及提醒系统前端 `web`
- 更新代码后重建 `web` 服务即可生效

## 验证建议

- 修改发送配置后点击“保存配置”，确认按钮会显示“保存中...”
- 保存完成后立即点击“测试邮箱”，确认不会再弹出“配置已修改但未保存”
- 若保存尚未完成就点击测试按钮，确认页面提示为“配置保存中，请稍候再测试”
