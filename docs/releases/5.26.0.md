# v5.26.0

## 功能优化

- 授权管理新增批量导入入口，支持 CSV/XLSX/XLS 文件上传。
- 授权管理新增授权导入模板下载，模板包含客户名称、授权名称、开始日期、到期日期、状态、备注、提醒天数。
- 授权导入会记录导入任务、展示成功/跳过统计与错误明细，并写入操作审计日志。

## 验证

- `node --check server/index.js`
- `node --check auth/index.js`
