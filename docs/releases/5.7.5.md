# 5.7.5

## 本次更新

- 修复发送配置页测试邮箱、测试短信、测试企业微信仍可能被误判为“未保存”的问题
- 测试按钮现在会按“当前业务配置”和“最近一次成功保存/加载的配置快照”做真实比对
- 安全配置页的改动不再误伤发送配置页的测试操作

## 部署说明

- 本次仅涉及提醒系统前端 `web`
- 更新代码后重建 `web` 服务即可生效

## 验证建议

- 打开发送配置页，先修改邮箱配置并保存，再点“测试邮箱”，确认不会再被提示先保存
- 修改安全配置但不保存时，返回发送配置页点击测试，确认不会被误判为发送配置未保存
- 修改任一发送渠道配置但未保存时，测试按钮仍应继续阻止发送
