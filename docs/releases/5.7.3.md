# 5.7.3

## 本次更新

- 修复提醒系统前端 `web` 将 `/api/auth/*` 错误代理到 `api:5179` 的问题
- 现在提醒系统前端的认证请求统一转发到 `auth:5180`
- 修复后，提醒系统未登录时会正常跳转统一登录，登录回跳后也能正确读取会话

## 部署说明

- 本次只涉及提醒系统前端 Nginx 配置
- 更新代码后重建 `web` 服务即可生效

## 验证建议

- 打开提醒系统，确认点击“前往统一登录”可以进入统一登录页
- 登录后重新进入提醒系统，确认不会再卡在“统一登录中”
- 直接访问 `/api/auth/me`，确认由前端网关返回统一登录服务的响应
