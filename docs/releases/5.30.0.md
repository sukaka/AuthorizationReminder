# v5.30.0

## 功能优化

- 客户、联系人、授权信息补齐后，系统自动为授权创建默认到期提醒计划。
- 自动提醒默认在到期前 90 天、60 天、30 天、7 天各提醒一次，默认使用企业微信。
- 手动发送计划功能保留；自动计划通过标记区分，不覆盖手动计划。
- 服务启动时会为已有客户、联系人、授权补齐自动提醒计划。
