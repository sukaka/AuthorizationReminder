# v5.17.1 发布说明

- Bug 修复：修复提示词发布后缺少可见反馈的问题。

- 保留归档操作，便于管理员继续调整提示词生命周期。
- 同步提示词管理中心、统一登录系统和根项目版本号为 `5.17.1`。
