# v5.31.0

## 功能优化

- 新增“我的授权”页面，普通用户可只读查看与本人联系方式匹配的客户授权。
- 匹配规则使用当前账号手机号、邮箱、企业微信，对应联系人管理中的启用联系人。
- 展示客户名称、授权名称、到期日期、剩余天数、授权状态和匹配联系人。

## 验证

- `node --test server/tests/my-licenses-source.test.js`
- `cd web && node --test src/my-licenses-source.test.js`
- `node --check server/index.js`
- `npm --prefix web run build`
