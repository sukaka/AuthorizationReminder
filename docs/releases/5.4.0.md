# 5.4.0 正式版（FAQ 分类批量删除与回收站彻底清理）

发布日期：2026-03-16
标签：`v5.4.0`
分支：`codex/5.4.0`

## 本次版本定位

- 版本类型：功能优化
- 版本升级：`5.3.0 -> 5.4.0`
- 判定依据：
  - FAQ 分类批量删除在父子分类同选时支持一次完成
  - FAQ 回收站新增单条与批量“彻底删除”能力
  - 这轮变更属于可感知的后台管理能力增强，不是纯缺陷修复

## 已完成

- FAQ 分类批量删除增强：
  - 新增已选分类深度排序
  - 已选子分类优先删除，已选父分类随后删除
  - 同层级继续保持原始勾选顺序
- FAQ 回收站清理增强：
  - 文章批量接口新增 `purge` 动作
  - 仅允许对回收站文章执行恢复或彻底删除
  - 彻底删除时复用既有硬删除逻辑，并补齐操作日志与系统事件
- FAQ 测试补齐：
  - 分类批量删除新增 helper 单测与 smoke 覆盖
  - 回收站彻底删除新增批量动作单测与 smoke 覆盖
- 经验记录补齐：
  - 新增分类批量删除修复记忆文件
  - 新增回收站彻底删除记忆文件

## 影响范围

- `POST /api/faq/categories/batch-delete`
- `POST /api/faq/articles/batch`
- FAQ 分类管理页的批量删除链路
- FAQ 回收站的恢复/彻底删除链路

## 发布注意事项

- FAQ 相关容器发布前，默认执行：
  - `./scripts/deploy/docker-compose-aliyun.sh pull mysql auth onlyoffice faq-api web-faq`
  - `./scripts/deploy/docker-compose-aliyun.sh up -d --build mysql auth onlyoffice faq-api web-faq`
- `purge` 仅适用于已在回收站中的文章；正常文章仍需先进入回收站。
