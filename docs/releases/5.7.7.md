# 5.7.7

## 本次更新

- 修复提醒系统发送配置保存时的 `CSRF token invalid`
- 提醒系统前端现在会从自己的 `/api/csrf` 刷新 CSRF token，不再误用统一登录服务的 `/api/auth/csrf`
- 提醒系统后端新增 `/api/csrf` 入口，避免与统一登录 CSRF 路径混用

## 部署说明

- 本次涉及提醒系统前端 `web` 与提醒系统后端 `api`
- 更新代码后重建 `web`、`api` 服务即可生效

## 验证建议

- 打开发送配置页，点击“保存配置”，确认不再返回 `403 {"error":"CSRF token invalid"}`
- 保存成功后再次测试邮箱，确认请求能继续进入邮件发送链路
