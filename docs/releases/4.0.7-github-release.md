# v4.0.7

## Highlights

- 认证服务完成一轮安全加固，补齐 `CSRF` 校验、会话绑定、弱密钥识别、内置账号默认密码轮换判定，并新增对应单元测试。
- FAQ 知识库补齐分类批量删除、强制删除与关联文章回收链路，前后端同步完善。
- Tender 系统新增解析工作台、起草工作台、知识入库、语义检索、评测 KPI、治理与校验规则库等核心能力，并补充 AI 任务契约文档。
- 培训考试系统补齐题库筛选/分类/导入、成绩中心相关能力，并将文档编辑器拆分为独立 `train-exam-onlyoffice`。

  - `POST /api/tender/bids/:id/generate/from-parse`

  - `POST /api/tender/evaluations/runs`
- FAQ:
  - `POST /api/faq/categories/batch-delete`
  - `POST /api/faq/categories/:id/force-delete`
- Train Exam:
  - `GET /api/train-exam/admin/results`
  - `GET /api/train-exam/admin/users/:userId/results`
  - `POST /api/train-exam/questions/bulk-publish`

## Deployment Notes

- `docker-compose.yml` 已切换为通过环境变量注入多项敏感配置，发布前请补齐：
  - `MYSQL_ROOT_PASSWORD`
  - `MYSQL_SHARED_APP_PASSWORD`
  - `AUTH_MYSQL_PASSWORD`
  - `AUTH_JWT_SECRET`
  - `AUTH_AUDIT_SIGNING_KEY`
  - `AUTH_CONFIG_SECRET_KEY`
  - `AUTH_BUILTIN_ACCOUNT_DEFAULT_PASSWORD`
  - `FAQ_MYSQL_PASSWORD`
  - `FAQ_DOC_EDITOR_JWT_SECRET`
  - `TRAIN_EXAM_MYSQL_PASSWORD`
  - `TRAIN_EXAM_AUDIT_SIGNING_KEY`
  - `TRAIN_EXAM_DOC_EDITOR_JWT_SECRET`
- `train-exam-api` 已切换到独立 `train-exam-onlyoffice`，不要再与 FAQ / Tender 共用 `DOC_EDITOR_JWT_SECRET`。
