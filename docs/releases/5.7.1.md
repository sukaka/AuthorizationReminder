# 5.7.1

## 本次更新

- 修复提醒系统 `api` 与统一登录 `auth` 使用不同 `CONFIG_SECRET_KEY` 的部署错误
- 现在发送配置中的邮箱密码会由 `api` 和 `auth` 使用同一把密钥加解密
- 修复后，批量导入用户邮件、管理员汇总邮件、测试邮箱发送会恢复正常解密链路

## 部署说明

- 本次只涉及部署配置，更新代码后需要重建 `api` 和 `auth` 服务
- 更新后请重新在“发送配置”里保存一次 SMTP 授权码，确保旧密文被新密钥链路重新写入

## 验证建议

- 在管理后台“发送配置”里重新保存邮箱授权码
- 分别验证测试邮箱发送、批量导入用户邮件、管理员汇总邮件
