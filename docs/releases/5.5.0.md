# 5.5.0

## 本次更新

- 用户管理的批量导入在创建成功后，会自动向已填写邮箱的用户发送账号开通邮件
- 邮件内容包含账号、初始密码和登录入口，方便直接通知到个人
- 导入结果 Excel 新增邮件发送状态与原因，便于追踪未发送或发送失败的用户

## 部署说明

- 本次更新只涉及统一登录与管理后台，升级后重建 `auth` 服务即可生效
- 使用前请先在发送配置中补齐 SMTP 参数，否则导入仍会创建用户，但邮件会标记为发送失败

## 验证建议

- 在管理后台导入一条带邮箱的测试账号，确认收到账号开通邮件
- 下载导入结果 Excel，确认 `notify_email_status` 和 `notify_email_reason` 列正常填充
