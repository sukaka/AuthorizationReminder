# v5.16.2 发布说明

## 版本类型

- Bug 修复：修复提示词创建页输入框和下拉框无法操作的问题。

## 变更内容

- 创建页表单不再因为当前账号没有负责人部门而整体禁用。
- 部门、标题、摘要、标签、内容和备注允许先填写，保存动作仍要求所选部门负责人权限。
- 选中非负责部门时显示明确提示，保存按钮保持禁用。
- 同步提示词管理中心、统一登录系统和根项目版本号为 `5.16.2`。
