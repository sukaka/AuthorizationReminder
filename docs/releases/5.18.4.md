# v5.18.4 发布说明

## 修复内容

- 修复提示词管理中心点击“退出登录”只返回门户、不清除统一登录态的问题。
- 退出时会先获取统一登录 CSRF token，再调用 `/api/auth/logout` 注销会话。
- 退出完成或请求失败后都会跳回统一登录入口，避免停留在业务系统内。
- 同步提示词管理中心、统一登录系统、提示词后端和根项目版本号为 `5.18.4`。

## 验证

- `npm --prefix prompt-center/frontend test`
- `npm --prefix prompt-center/frontend run build`
- `node --test auth/tests/login-page-version.test.js`
