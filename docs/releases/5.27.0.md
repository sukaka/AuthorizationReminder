# v5.27.0

## 功能优化

- 授权管理的客户名称改为可手动输入的联想控件，不再受当前客户分页限制。
- 新增/编辑授权支持按客户名称自动匹配已有客户；输入新客户名称时自动创建客户。
- 客户管理列表操作区新增“新增授权”按钮，点击后跳转授权管理并自动带入客户名称。

## 验证

- `node --test web/src/license-customer-input-source.test.js`
- `node --test server/tests/license-customer-name-source.test.js`
- `node --check server/index.js`
- `npm --prefix web run build`
