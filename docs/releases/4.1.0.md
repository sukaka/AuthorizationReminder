# 4.1.0 正式版（独立后台与用户管理增强）

发布日期：2026-03-14
标签：`v4.1.0`
分支：`codex/4.1.0`

## 本次版本定位

- 版本类型：功能优化
- 版本升级：`4.0.9 -> 4.1.0`
- 判定依据：
  - 新增独立 `admin-center` / `audit-center`
  - `sysadmin` / `auditor` 登录后不再依赖 `reminder` 作为默认后台入口
  - `admin-center` 补齐用户导入、模板下载、编辑用户、中文系统权限展示等一批可感知功能增强

## 已完成

- 统一认证服务内新增独立后台入口：
  - `GET /admin-center`
  - `GET /audit-center`
- 门户路由升级：
  - `sysadmin` 默认进入 `admin-center`
  - `auditor` 默认进入 `audit-center`
- `admin-center` 用户管理增强：
  - 用户列表
  - 新增用户
  - 编辑用户
  - 启用 / 禁用
  - 解锁
  - 重置密码
  - 删除用户
  - 批量导入（Excel）
  - 下载导入模板
  - 最近一次导入摘要
- `admin-center` 安全能力增强：
  - 当前账号密码修改
  - 当前账号 MFA / 谷歌认证
  - 全局安全配置读写
- `audit-center` 审计能力增强：
  - 审计日志查询
  - 审计链校验
  - CSV 导出
- 可访问系统统一使用中文展示：
  - 用户列表
  - 编辑用户弹层
  - 审计中心系统列
- 版本规范落地：
  - 新增系统级版本文档
  - `bootstrap-full-server.sh`、README、部署文档统一切换到 `4.1.0`

## 关键接口

- `GET /api/admin-center/users`
- `POST /api/admin-center/users`
- `PUT /api/admin-center/users/:id`
- `POST /api/admin-center/users/import`
- `GET /api/admin-center/users/template.xlsx`
- `GET /api/admin-center/security`
- `POST /api/admin-center/security`
- `GET /api/audit-center/logs`
- `GET /api/audit-center/logs/export`
- `GET /api/audit-center/logs/verify`

## 发布注意事项

- 升级服务器时，建议直接切换到分支 `codex/4.1.0`
- 如果服务器仍为 `HTTP` 入口，保持：
  - `AUTH_COOKIE_SECURE=false`
  - `AUTH_SECURITY_STRICT_MODE=false`
- 如果提供了 `HTTPS`，再一起改成 `true`
- `PUBLIC_HOST` 仍需写公网 IP 或域名，不带协议和端口
