# 5.4.1 正式版（前端端口口径与部署构建修复）

发布日期：2026-04-15
标签：`v5.4.1`
分支：`codex/5.4.1`

## 本次版本定位

- 版本类型：Bug 修复
- 版本升级：`5.4.0 -> 5.4.1`
- 判定依据：
  - 本次主要修复前端访问端口、默认 CORS 来源、部署脚本默认启动方式与培训考试镜像构建上下文
  - 变更集中在兼容性、部署稳定性和文档口径统一，不属于新增业务能力

## 已完成

- 前端访问端口统一修正：
  - 对外访问端口从 `8080-8087` 统一调整为 `18080-18087`
  - 统一登录默认入口、各系统运行时默认地址与脚本校验口径同步更新
  - 各独立前端开发端口同步到 `1808x`
- 运行时来源校正：
  - `auth` 与各业务后端默认 CORS 白名单更新到新端口
  - `PUBLIC_HOST` 相关测试与文档同步更新
- 部署脚本降噪：
  - `docker-compose-aliyun.sh` 新增 `start` 与 `rebuild` 别名
  - 日常启动默认走 `start`，避免误把 `up -d --build` 当成普通启动
  - 新服务器首启脚本同步切到新用法
- 培训考试构建优化：
  - `train-exam-api` 构建上下文从仓库根目录收紧到后端子目录
  - 为培训考试前后端补充本地 `.dockerignore`
  - 将 `cors-origin.js` 下沉到培训考试后端目录，减少无关上下文传输
- 回归测试补齐：
  - 新增前端端口迁移源码断言测试
  - 新增 `docker-compose-aliyun.sh` 命令别名测试

## 影响范围

- Docker Compose 前端访问端口映射
- 统一登录默认门户地址与各系统默认 CORS 来源
- `scripts/deploy/docker-compose-aliyun.sh`
- `scripts/deploy/bootstrap-new-server.sh`
- 培训考试前后端镜像构建链路

## 发布注意事项

- 日常启动建议执行：
  - `./scripts/deploy/docker-compose-aliyun.sh start`
- 代码或镜像变更后再执行：
  - `./scripts/deploy/docker-compose-aliyun.sh rebuild`
- 培训考试系统发布后，如需单独刷新，可执行：
  - `./scripts/deploy/docker-compose-aliyun.sh rebuild train-exam-api web-train-exam`
