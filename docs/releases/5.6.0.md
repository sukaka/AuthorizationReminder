# 5.6.0

## 本次更新

- 批量导入用户后，除了给每位用户发送个人开通邮件，还会给 `admin` 邮箱发送本次导入账号与初始密码汇总
- 新导入用户默认标记为“首次登录必须修改密码”
- 用户首次登录成功后，如果尚未修改初始密码，将被强制跳转到改密流程，改完后再重新登录
- 管理员手工重置密码后，也会自动要求该用户下次登录先修改密码

## 部署说明

- 本次更新涉及统一登录数据库结构与认证逻辑，升级后请重建 `auth` 服务
- 首次启动新版本时会自动补齐 `users.must_change_password` 字段
- 若要让管理员收到汇总邮件，请确保 `admin` 账号资料中已配置邮箱，且 SMTP 配置完整

## 验证建议

- 导入一批测试用户，确认个人邮件与 `admin` 汇总邮件都能收到
- 用新导入用户首次登录，确认系统会先要求修改密码
- 修改密码成功后重新登录，确认可正常进入系统
