# v5.29.0

## 功能优化

- 授权管理截图栏新增“按已上传处理”，可在没有截图文件时手动标记为已上传状态。
- “未上传截图”筛选会排除已手动标记的授权；清除截图状态会同时清除真实截图和手动标记。

## 验证

- `node --test server/tests/license-screenshot-manual-source.test.js`
- `cd web && node --test src/license-screenshot-manual-source.test.js`
- `node --check server/index.js`
- `npm --prefix web run build`
