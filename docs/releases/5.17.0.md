# v5.17.0 发布说明

## 版本类型

- 功能优化：提示词分类层级调整为两级。

## 变更内容

- 提示词创建页移除三级分类下拉框，只保留一级分类和二级分类。
- 二级分类现在直接作为提示词保存时的所属分类。
- 提示词列表页的分类目录最多展示两级分类。
- 部门分类管理中只允许在一级分类下创建二级分类，不再创建三级分类。
- 同步提示词管理中心、统一登录系统和根项目版本号为 `5.17.0`。

## 验证

- `npm --prefix prompt-center/frontend test`
- `npm --prefix prompt-center/frontend run build`
- `node --test auth/tests/login-page-version.test.js`
