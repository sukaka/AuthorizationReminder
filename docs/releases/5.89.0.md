## 发布摘要

本次把桌面端从“启动后直接加载远程页面”改为“本地启动页 + 独立远程工作台窗口”，并加入受信任的签名更新流程：

- 无网络或远程服务故障时仍显示本地产品介绍、连接设置和恢复操作，消除无说明白屏。
- 登录前可填写、校验、测试和保存远程服务地址；生产构建仅接受 HTTPS，开发构建仅额外允许 loopback HTTP。
- 测试成功后复用现有统一 SSO，在独立工作台窗口中加载业务页面；工作台故障时返回本地启动页。
- 远程 IPC 同时校验窗口、精确 Origin 和已绑定用户；更新地址与公钥保持构建期固定。
- 支持启动延迟检查、周期检查、手动检查、24 小时稍后提醒、下载进度与取消、签名校验、安装和自动重启。
- 草稿和待同步记录按“服务器 Origin + SSO 用户”隔离，切换服务器不会跨服务器同步本机数据。
- 损坏的服务器配置会被安全隔离并回到可操作启动页；启动页提供受保护的本机草稿/待同步状态面板，工作台侧栏也可手动检查更新。
