# 授权到期提醒系统（Reminder）需求说明书

## 1. 系统概述
- 系统名称：授权到期提醒系统
- 前端：`http://localhost:8080`
- 后端：`http://localhost:5179`
- 数据库：`juxin_reminder`

## 2. 建设目标
- 建立客户/联系人/授权信息台账。
- 基于到期日自动提醒与人工触发提醒。
- 提供操作日志与审计追踪能力。

## 3. 业务范围
- 客户管理、联系人管理、授权管理。
- 提醒计划配置、提醒发送与记录追踪。
- 账号与安全配置（按角色）。

## 4. 角色与权限需求
- `admin`：业务管理与配置写权限。
- `sysadmin`：用户/安全管理。
- `auditor`：仅审计相关菜单（操作日志）。
- `sales`：仅本人业务范围内数据。

## 5. 功能需求
1. 主数据管理
- 维护客户、联系人、授权记录。
- 支持筛选、分页、导入导出。

2. 到期提醒
- 支持按规则自动触发提醒。
- 支持手动补发与发送记录查询。

3. 审计追踪
- 记录关键操作日志（新增/修改/删除/发送）。
- 支持按时间、用户、动作检索。
- 日志包含来源 IP。
- 日志变更信息以前端中文“变更摘要”展示，不直接展示原始 JSON。

## 6. 接口需求
- 客户、联系人、授权 CRUD 接口。
- 提醒发送与提醒日志接口。
- 审计日志查询接口。

## 7. 非功能需求
- 数据一致性：提醒发送状态与日志一致。
- 安全：敏感配置加密存储，接口启用 CSRF 防护。
- 可观测性：关键失败需可追踪。

## 8. 验收标准
- 到期规则可正确触发提醒。
- 业务角色不可越权访问不在范围的数据。
- `auditor` 只能查看审计菜单，不能看到业务菜单。
