# CMDB 系统需求说明书

## 1. 系统概述
- 系统名称：CMDB 系统
- 前端：`http://localhost:8090`
- 后端：`cmdb`（容器内 `:8088`）
- 系统键：`cmdb`
- 数据库：MySQL `cmdb` + Mongo（扩展）

## 2. 建设目标
- 建立配置项（CI）统一管理能力。
- 支撑配置项关系维护与审计留痕。
- 支撑资产总览看板。

## 3. 业务范围
- CI 列表/查询/详情。
- CI 新增、更新、删除。
- CI 关系新增/更新。
- 看板汇总。

## 4. 角色与权限需求
- `admin`/`sysadmin`：CI 与关系写权限。
- `auditor`：仅审计相关页面和只读查询。
- 后端必须拦截 `auditor` 的写请求，不能仅依赖前端隐藏按钮。

## 5. 功能需求
1. CI 管理
- 支持按类型、状态、关键词检索。
- 支持版本控制字段与变更审计。

2. 关系管理
- 支持配置项关系维护（依赖、连接、归属等）。
- 关系变更需纳入审计。

3. 审计与治理
- 记录操作人、角色、请求链路信息。
- 审计日志需包含来源 IP。
- 日志变更信息以前端中文“变更摘要”展示，不直接展示原始 JSON。
- 支持后续扩展审计查询接口。

## 6. 接口需求
- `/api/v1/dashboard/overview`
- `/api/v1/ci`（GET/POST）
- `/api/v1/ci/:ci_uid`（GET/PATCH/DELETE）
- `/api/v1/ci/:ci_uid/relations`（POST）

## 7. 非功能需求
- 鉴权：统一 introspect，按系统键放行。
- 稳定性：支持限流、超时与请求体大小限制。
- 可扩展：预留事件总线/outbox 能力。

## 8. 验收标准
- CI 全量 CRUD 功能可用。
- 未授权角色调用写接口返回 403。
- `auditor` 仅能访问只读能力与审计相关菜单。
