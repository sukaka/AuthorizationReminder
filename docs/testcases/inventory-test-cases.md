# 库存系统测试用例

## 前置条件
- 服务可访问：`http://localhost:5183`
- 已获取具备 inventory 权限的 Token
- 物流网关可访问：`http://localhost:5190`

## 用例清单
| 用例ID | 场景 | 步骤 | 预期结果 |
|---|---|---|---|
| INV-001 | 健康检查 | `GET /api/health` | 返回 200，`ok=true` |
| INV-002 | 商品管理 | 新建商品、编辑商品、停用商品 | 状态变更正确，列表可见 |
| INV-003 | 存放位置与使用位置 | 新建仓库位置与使用位置 | 数据保存成功，可用于出入库 |
| INV-004 | 入库流程 | 执行 `stock-in`，含批次与SN | 库存余额增加，流水记录生成 |
| INV-005 | 出库流程 | 执行 `stock-out` 指定使用位置 | 库存余额减少，流水记录生成 |
| INV-006 | 库存台账 | 查询 `inventory/balances` | 余额与入出库累计一致 |
| INV-007 | 低库存预警 | 构造低于安全库存场景 | `low-stock` 返回对应商品 |
| INV-008 | 发货流程 | 从出库单创建发货单并更新状态 | 状态按 `PENDING->SHIPPED->IN_TRANSIT->SIGNED/EXCEPTION` 流转 |
| INV-009 | 物流轨迹查询 | 查询发货单轨迹 | 返回库存本地轨迹和/或网关轨迹 |
| INV-010 | 权限控制 | viewer/sales 调写接口 | 返回 403 |
| INV-011 | 审计字段完整性 | 执行一次写操作后查询审计日志 | 日志包含来源 IP，变更内容为中文“变更摘要” |
| INV-012 | auditor 菜单边界 | auditor 登录库存系统 | 仅可见“审计日志”菜单，不可见业务菜单 |

## 建议执行命令
```bash
curl -sS http://localhost:5183/api/health
```
