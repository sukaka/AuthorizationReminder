# 授权到期提醒系统测试用例

## 前置条件
- 服务可访问：`http://localhost:5179`
- 已获取 `admin` Token
- 数据库已初始化

## 用例清单
| 用例ID | 场景 | 步骤 | 预期结果 |
|---|---|---|---|
| REM-001 | 健康检查 | `GET /api/health` | 返回 `{"ok":true}` |
| REM-002 | 仪表盘读取 | `GET /api/dashboard` | 返回 200，含统计字段 |
| REM-003 | 客户管理读写 | 新建客户后查询列表 | 新建成功，列表可查询到 |
| REM-004 | 联系人管理（多客户关联） | 新建联系人并关联多个客户 | 保存成功，查询回显正确 |
| REM-005 | 授权管理 | 新建授权并设置到期日期 | 记录成功，可在列表查看 |
| REM-006 | 发送计划创建与立即发送 | 新建发送计划并触发立即发送 | 任务执行成功，发送日志可查 |
| REM-007 | 渠道配置校验 | 邮件/短信/企业微信配置保存与测试发送 | 保存成功，测试发送返回成功或明确失败原因 |
| REM-008 | 审计日志查询导出 | 查询 `operation-logs` 并导出 | 列表与导出文件均可用 |
| REM-009 | 审计验签 | `GET /api/operation-logs/verify` | 返回 200，可定位异常记录 |
| REM-010 | 权限隔离 | 用非 admin 调 admin 接口 | 返回 403 |
| REM-011 | 审计字段完整性 | 执行一次写操作后查询操作日志 | 新日志含来源 IP，变更内容为中文“变更摘要” |
| REM-012 | auditor 菜单边界 | auditor 登录提醒系统 | 仅可见“操作日志”，不可见业务菜单 |

## 建议执行命令
```bash
curl -sS http://localhost:5179/api/health
```
