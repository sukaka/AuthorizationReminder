# 工单系统测试用例

## 前置条件
- 服务可访问：`http://localhost:5182`
- 已获取具备 ticketing 权限的 Token

## 用例清单
| 用例ID | 场景 | 步骤 | 预期结果 |
|---|---|---|---|
| TIC-001 | 健康检查 | `GET /health` | 返回 `{"ok":true}` |
| TIC-002 | 工单列表 | `GET /api/tickets?page=1&limit=10` | 返回 200，分页字段正确 |
| TIC-003 | 新建工单 | `POST /api/tickets` 创建普通工单 | 返回 201，生成工单号 |
| TIC-004 | 工单状态流转 | 按 `新建->受理->处理中->待验证->完成->关闭` 推进 | 合法流转成功，非法跳步被拒绝 |
| TIC-005 | 高风险审批门禁 | 创建 P1/HIGH 工单并直接关闭 | 未审批前关闭被拒绝 |
| TIC-006 | 评论与@通知 | 新增评论并@人员 | 评论成功，通知中心可见 |
| TIC-007 | SLA 看板 | `GET /api/dashboard/sla-groups` | 返回即将超时/已超时分组 |
| TIC-008 | 项目权限矩阵 | 配置项目权限后访问工单 | 仅授权角色可见/可操作 |
| TIC-009 | 附件上传下载 | 上传附件并下载内容 | 上传成功，下载内容一致 |
| TIC-010 | 审计事件导出 | 导出工单事件日志 | 导出成功，字段完整 |

## 建议执行命令
```bash
curl -sS http://localhost:5182/health
```
