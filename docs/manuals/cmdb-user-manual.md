# CMDB 系统用户使用手册

## 1. 系统信息
- 前端地址：`http://localhost:8090`
- 系统键：`cmdb`

本系统用于配置项（CI）管理、关系维护、资产统计和审计追踪。

## 2. 角色与菜单
### 2.1 角色口径
| 角色 | 权限说明 |
|---|---|
| `admin` / `sysadmin` | 可执行 CI 与关系写操作 |
| `auditor` | 仅可见审计日志页面 |

### 2.2 菜单
业务菜单（admin/sysadmin）：
- 仪表盘
- 资产管理（服务器/数据库/网络设备/中间件）
- 模型管理
- 关系管理（拓扑视图/关系列表）
- 自动发现
- 报表分析

审计菜单（auditor）：
- 审计日志

## 3. 资产管理
### 3.1 资产维护操作
在资产页内提供 3 个子页签：
1. 资产查询：按 CI 唯一编号查询资产。
2. 新增资产：创建 CI，填写类型、名称、唯一标识、状态、来源、归属人、扩展属性等。
3. 资产更新：按 CI 编号与版本更新资产。

### 3.2 列表与筛选
- 支持按关键字、状态、归属人筛选。
- 支持分页。

### 3.3 导入与导出
- 导入支持：`json`、`csv`、`xlsx`。
- 导出支持：按提示选择格式导出。

## 4. 关系管理
### 4.1 拓扑视图
用于查看资产依赖链路的可视化关系。

### 4.2 关系列表与维护
1. 查看现有关系清单。
2. 填写源 CI、目标 CI、关系类型、关系属性。
3. 保存后生效。

## 5. 其他页面说明
- 自动发现：已提供页面入口，后续可扩展任务与执行日志。
- 报表分析：已提供页面入口，后续可扩展图表与报表导出。

## 6. 审计日志（含来源 IP）
1. 进入“审计日志”。
2. 支持筛选条件：操作人、动作、状态、来源 IP、关键字、日期范围。
3. 列表字段：时间、操作人、动作、资源、方法、状态、来源 IP、请求 ID。
4. 支持分页与导出 CSV。

## 7. 常见问题
### 7.1 auditor 看不到资产菜单
这是设计行为。`auditor` 仅允许审计视图。

### 7.2 导入失败
请检查：
1. 文件格式是否为 json/csv/xlsx。
2. 必填字段（如资产名称、唯一标识）是否完整。

### 7.3 写接口返回 403
当前角色缺少写权限，请使用 `admin` 或 `sysadmin`。
