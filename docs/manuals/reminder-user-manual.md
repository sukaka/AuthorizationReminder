# 授权到期提醒系统（Reminder）用户使用手册

## 1. 系统信息
- 前端地址：`http://localhost:8080`
- 后端地址：`http://localhost:5179`
- 系统键：`reminder`

本系统用于维护客户与授权台账，执行到期提醒，保留操作审计。

## 2. 角色与菜单
### 2.1 角色菜单矩阵
| 角色 | 可见菜单 |
|---|---|
| `admin` | 仪表盘、客户管理、联系人管理、授权管理、发送、提醒记录、导入记录、账号安全、发送配置 |
| `sysadmin` | 账号安全、安全配置、用户管理 |
| `auditor` | 操作日志 |
| `viewer`/`sales` | 账号安全 |

说明：
- `auditor` 在提醒系统是“纯审计视图”。
- `admin` 默认不显示“操作日志”菜单；审计相关由 `auditor` 角色使用。

## 3. 进入系统
1. 从统一门户进入提醒系统。
2. 顶部显示当前登录用户。
3. 若会话过期，会自动返回统一登录页。

## 4. 业务操作
### 4.1 客户管理
1. 进入“客户管理”。
2. 新增客户，维护客户名称、聚信销售、渠道销售等信息。
3. 支持搜索、分页、编辑、删除。

### 4.2 联系人管理
1. 进入“联系人管理”。
2. 新增联系人时可关联多个客户。
3. 支持按联系人状态、客户、关键字筛选。

### 4.3 授权管理
1. 进入“授权管理”。
2. 新增授权记录，填写授权名称、起止日期、状态、提醒天数。
3. 支持按客户、状态、到期区间筛选。
4. 支持附件/截图留证上传（用于补充授权证明材料）。

### 4.4 发送（自动计划 + 手动发送）
1. 进入“发送”。
2. 在“自动提醒计划”配置：
- 计划名称
- 关联授权和联系人
- 提醒天数（如 `60,30,20`）
- 发送渠道（邮件/短信/企业微信）
3. 可批量勾选计划执行“立即发送”。
4. 发送结果在“提醒记录”中查询。

### 4.5 提醒记录
1. 进入“提醒记录”。
2. 按客户、状态、天数、日期区间筛选。
3. 失败记录可执行“重新发送”。

### 4.6 导入记录
1. 进入“导入记录”。
2. 查看每次导入任务状态（成功/失败）。
3. 可展开导入错误详情（行号与原因）。

## 5. 系统配置
### 5.1 账号安全（个人）
- 修改密码。
- 管理二次认证（验证码、TOTP/谷歌认证）。

### 5.2 发送配置（管理员）
- 配置邮件、短信、企业微信渠道参数。
- 支持发送测试消息，验证渠道可用性。

### 5.3 安全配置（系统管理员）
- 登录验证码策略。
- 二次认证策略。
- 密码/锁定策略（按系统配置项）。

### 5.4 用户管理（系统管理员）
- 新增/编辑用户。
- 分配角色。
- 分配系统访问权限 `app_access`（跨系统入口权限）。

## 6. 审计操作（auditor）
1. 进入“操作日志”。
2. 可按操作人、动作、对象、日期范围筛选。
3. 支持查看中文“变更摘要”（新增/移除/字段修改），不直接展示原始 JSON。
4. 支持导出 CSV。
5. 可执行“审计验签”，并导出核验报告。
6. 日志包含来源 IP 字段，便于追溯。

## 7. 常见问题
### 7.1 无法发送提醒
检查顺序：
1. 发送配置是否已保存。
2. 联系人联系方式是否完整。
3. 目标授权是否在提醒窗口内。

### 7.2 导入失败
1. 在“导入记录”查看错误行和错误原因。
2. 修复后重新导入。

### 7.3 看不到某些菜单
由角色决定。请确认当前账号角色是否与目标菜单匹配。
