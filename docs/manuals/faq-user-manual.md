# FAQ 系统用户手册

## 1. 入口
- 统一登录后，在门户选择“FAQ系统”。
- 地址：`http://localhost:8085`

## 2. 角色说明
- `admin`：可管理 FAQ 全生命周期（含置顶、批量、回收站维护）。
- `editor`：可新建、上传、在线编辑。
- `reviewer`：可审批发布、直接发布。
- `auditor`：可查看审计日志与事件出站队列。
- 其他拥有 FAQ 访问权限的用户：可查看、预览、下载、收藏、反馈。

## 3. 常用操作
### 3.1 新建 FAQ
1. 进入“FAQ管理”。
2. 填写标题、摘要、标签、分类。
3. 点击“新增FAQ”。

### 3.2 上传文档版本
1. 打开目标 FAQ 详情。
2. 点击“上传版本”。
3. 选择 `doc/docx/pdf` 文件。

### 3.3 在线编辑 Word
1. 打开 FAQ 详情。
2. 点击“在线编辑Word”。
3. 编辑器自动保存草稿。
4. 点击“发布草稿”生成新版本。

### 3.4 版本回滚
1. 在“版本历史”找到目标版本。
2. 点击“回滚”。
3. 系统会基于该版本生成一个新的当前版本。

### 3.5 发布审批
1. 打开 FAQ 详情，点击“发布/提审发布”。
2. 选择目标版本，查看发布前校验结果。
3. 填写发布说明并提交。
4. `reviewer/admin` 可在“发布审批”菜单执行通过/拒绝。

### 3.6 收藏与反馈
1. 在列表或详情点击“收藏/取消收藏”。
2. 在详情页“反馈闭环”中提交“已解决/未解决”与原因。
3. 仪表盘可查看反馈总量与解决率。

### 3.7 在线协作编辑
1. 点击“在线编辑Word”进入编辑器。
2. 若开启分段协作，可锁定/释放分段并查看持锁人。
3. 支持自动保存，完成后可发布草稿或放弃草稿。

## 4. 常见问题
- 编辑器不可用：系统会降级为“预览+下载”，可稍后重试在线编辑。
- 无法编辑：请确认账号角色具备 FAQ 写权限（`admin/editor`）。
- 上传失败：请检查文件类型是否为 `doc/docx/pdf`，且大小未超限制。
