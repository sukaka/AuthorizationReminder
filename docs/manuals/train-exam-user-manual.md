# 培训考试系统用户手册

## 1. 入口
- 统一登录后，在门户选择“培训考试系统”。
- 地址：`http://localhost:8087`

## 2. 角色说明
- `admin`：全量管理与审计能力。
- `editor`：课程与题库维护（含导题）。
- `reviewer`：题目审核、试卷发布。
- `auditor`：查看审计日志与 AI 日志。
- 普通用户：参加考试、查看个人成绩和证书。

## 3. 常用操作
### 3.1 创建课程
1. 进入“培训管理”。
2. 填写课程标题、时长、描述。
3. 点击“创建课程”。

### 3.2 新增培训资源
1. 在“培训管理”中填写课程ID与资源信息。
2. 选择资源类型（文档/视频/外链）。
3. `upload` 模式下可继续上传文件。

### 3.3 FAQ 自动出题
1. 进入“题库管理”。
2. 创建“自动出题任务”，填写 FAQ 分类/文章范围。
3. 依次执行“执行任务”“审核发布”。

### 3.4 Excel 导题
1. 在“题库管理”下载导题模板。
2. 按模板填题后上传 Excel。
3. 查看导入成功/失败统计。

### 3.5 创建并发布试卷
1. 进入“试卷管理”。
2. 选择固定试卷或随机抽题。
3. 设置及格线、时长、最大次数。
4. 创建后点击“发布”。

### 3.6 参加考试
1. 在“试卷管理”点击“开始考试”。
2. 在“考试中心”作答并提交。
3. 页面会显示剩余时间和切屏计数。

### 3.7 查看成绩与证书
1. 进入“成绩证书”。
2. 查看成绩明细、是否通过。
3. 通过后点击“生成证书”，再下载证书。

## 4. 常见问题
- 看不到系统入口：确认账号 `app_access` 包含 `train-exam`。
- 导题失败：检查 Excel 字段和 JSON 格式。
- 证书无法下载：请先生成证书并确认成绩为通过。
- 试卷无法发布：检查试卷是否配置了题目（fixed）或规则（random）。
