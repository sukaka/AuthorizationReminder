# 库存管理系统（Inventory）用户使用手册

## 1. 系统信息
- 前端地址：`http://localhost:8082`
- 后端地址：`http://localhost:5183`
- 物流网关：`http://localhost:5190`
- 系统键：`inventory`

本系统覆盖商品主数据、出入库、发货、盘点、追溯、审计。

## 2. 角色与菜单
### 2.1 权限口径
| 角色 | 权限说明 |
|---|---|
| `admin` | 主数据与库存业务可读写，支持审计查看导出 |
| `sysadmin` | 与 `admin` 同口径（库存场景） |
| `auditor` | 仅可见“审计日志”菜单 |
| 其他角色 | 仅只读或无权限（按后端授权） |

### 2.2 菜单列表
- 系统总览
- 库存仪表盘
- 商品管理
- 商品存放位置
- 商品使用位置
- 入库管理
- 出库管理
- 发货管理
- 盘点管理
- 批次与序列号
- 库存台账
- 流水明细
- 审计日志（审计员专用）

## 3. 推荐使用顺序
1. 先维护主数据：商品、存放位置、使用位置。
2. 再执行业务单据：入库、出库、发货、盘点。
3. 最后做核对：台账、流水、审计日志。

## 4. 核心业务操作
### 4.1 商品管理
1. 进入“商品管理”。
2. 录入商品编码、名称、分类、单位、安全库存。
3. 保存后在商品列表核对库存状态（含低库存标记）。

### 4.2 存放位置与使用位置
1. 进入“商品存放位置”维护仓库/区域/货架/货位。
2. 进入“商品使用位置”维护部门/机房等领用场景。

### 4.3 入库管理
1. 进入“入库管理”。
2. 填写供应商、备注，并添加入库行：商品、存放位置、数量、单价、批次、序列号。
3. 提交后库存自动增加。
4. 可在“最近入库单”查看并按权限编辑。

### 4.4 出库管理
1. 进入“出库管理”。
2. 填写出库目标（使用位置）和出库行。
3. 提交后库存自动扣减。
4. 可从出库单直接跳转“去发货”。

### 4.5 发货管理
1. 进入“发货管理”。
2. 关联出库单并可拆分多个物流单。
3. 维护承运商、快递单号、收件信息、发货状态。
4. 支持：
- 编辑发货单（可拖动弹窗）
- 查看发货详情（可拖动弹窗）
- 查看物流轨迹
- 打印发货清单

### 4.6 盘点管理
1. 进入“盘点管理”。
2. 录入实盘数量并提交。
3. 系统自动生成差异并写入库存流水。

### 4.7 追溯与台账
- “批次与序列号”：按批次号/SN 回溯入库、出库、在库状态。
- “库存台账”：按商品 + 库位查看实时库存。
- “流水明细”：查询全部 IN/OUT/ADJUST 变更。

## 5. 仪表盘与运营视图
- 系统总览：库存、位置、低库存预警。
- 库存仪表盘：趋势、结构、库位热力、风险预测。
- 支持大屏模式与全屏展示。

## 6. 审计日志（含来源 IP）
1. 进入“审计日志”。
2. 按操作人、动作、实体、关键字、时间筛选。
3. 支持分页和每页条数切换。
4. 变更内容以中文“变更摘要”展示（新增/移除/字段修改），不直接展示原始 JSON。
5. 支持导出表格。

## 7. 常见问题
### 7.1 无法提交入库/出库/发货/盘点
当前角色可能无库存写权限，请联系管理员确认角色。

### 7.2 发货状态无法更新
先确认发货单 ID 有效，且状态流转符合规则。

### 7.3 审计导出按钮不可用
通常是无数据或当前角色无审计权限。
