# 工单管理系统（Ticketing）用户使用手册

## 1. 系统信息
- 前端地址：`http://localhost:18081`
- 后端地址：`http://localhost:5182`
- 系统键：`ticketing`

本系统用于工单全流程管理、项目协作、模板化交付、审计追踪。

## 2. 角色与菜单
### 2.1 角色权限概要
| 角色 | 权限特征 |
|---|---|
| `admin` | 全功能读写（含项目权限配置） |
| `sysadmin` | 只读口径，不能执行业务写入 |
| `auditor` | 仅审计菜单（操作日志、项目权限只读） |
| 业务用户 | 按项目/工单授权访问 |

### 2.2 菜单差异
- `auditor`：`操作日志`、`项目权限（只读）`
- 非 `auditor`：`工单管理`、`项目管理`、`模板管理`、`通知中心`、`甘特图`、`工单日历`
- `admin` 额外可见：`项目权限`

## 3. 常用流程
### 3.1 新建项目（建议先建项目）
1. 进入“项目管理”。
2. 填写项目基础信息并保存。
3. （仅 `admin`）进入“项目权限”配置成员权限。

### 3.2 新建工单
1. 进入“工单管理”。
2. 点击“新建工单”。
3. 填写核心字段：标题、描述、优先级、严重级别、负责人、所属项目、SLA 时长等。
4. 提交后进入工单详情。

### 3.3 工单协作
1. 在工单详情维护协作人和观察者。
2. 根据模板生成阶段任务。
3. 更新阶段状态、交付物、排期。
4. 按流程进行审批（通过/驳回）。

### 3.4 附件与评论
- 可在工单详情上传附件并发表评论。
- `auditor` 和 `sysadmin` 为只读口径，不允许业务写入评论。

### 3.5 计划视图
- “甘特图”：查看项目排期和里程碑。
- “工单日历”：按月查看工程师排程。

## 4. 审计与导出
### 4.1 操作日志
1. 进入“操作日志”。
2. 按操作人、时间范围筛选。
3. 查看来源 IP 与中文“变更摘要”。

### 4.2 项目权限（只读）
1. 进入“项目权限”。
2. 查看项目成员权限与变更流水（只读）。
3. 需要导出时可使用页面导出功能。

说明：审计列表已包含来源 IP 字段，便于安全追溯。

## 5. 典型权限边界
- 非管理员不能修改项目权限。
- `auditor` 不能创建/编辑/关闭工单。
- `sysadmin` 在工单系统为只读，不执行写操作。

## 6. 常见问题
### 6.1 看不到“项目权限”菜单
仅 `admin` 显示该菜单。

### 6.2 不能上传附件或发表评论
当前角色可能是只读角色（`auditor` 或 `sysadmin`）。

### 6.3 审计导出为空
请检查筛选条件是否过严（时间范围、操作人、项目条件）。
