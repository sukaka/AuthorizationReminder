# 聚信 AI 助手桌面端使用手册

## 1. 首次启动与统一登录

桌面应用每次启动都会先打开安装包内置的本地启动页。即使企业服务未启动、网络不可用或地址配置错误，启动页仍会显示产品简介、远程服务地址、连接状态和恢复操作，不会只显示白屏。

首次使用：

1. 在“远程服务地址”中填写管理员提供的聚信 AI 助手地址，例如 `https://ai.example.com`。
2. 点击“测试连接”。只有地址格式、TLS 连接和桌面协议都验证通过后，“使用统一登录”才可用。
3. 点击“使用统一登录”。应用会打开独立工作台窗口，并继续使用公司现有的聚信 SSO。
4. 完成登录后进入员工工作台；桌面端不会要求或保存独立账号密码。

正式安装包只接受 HTTPS Origin，不接受用户名、密码、路径、查询参数或片段。`http://localhost`、`http://127.0.0.1` 和 `http://[::1]` 仅供启用了开发标记的本地开发构建使用，不能在正式安装包中开启。

更换服务器时，应用会显示旧主机和新主机并要求二次确认。确认后会清理当前 SSO 本地绑定和工作台 Cookie；原服务器的草稿与待同步数据不会同步到新服务器。

### 连接失败时

- 地址格式错误：按输入框下方提示改为有效 HTTPS Origin，再重新测试。
- DNS、连接超时、TLS 或证书失败：确认网络、证书和服务状态后点击“重新测试”。
- 产品或协议不兼容：核对是否填写了正确的聚信 AI 助手服务地址，并联系管理员升级服务端。
- 工作台加载失败、退出登录或网络中断：应用会关闭故障工作台并回到本地启动页，可重试或修改地址。
- 本机服务器配置损坏：应用会隔离损坏文件并继续显示启动页，按中文提示重新填写和测试地址。
- 更新服务不可用：只影响更新检查，不影响当前版本登录和使用。

## 2. 访问角色

桌面端统一使用聚信 SSO，不提供独立账号或密码。账号没有 `ai-assistant` 应用权限时会显示无权限页，可返回统一门户联系管理员开通。

| 角色 | 可用能力 |
| --- | --- |
| 普通员工 | 工作台、八类助手、任务执行、个人模型、历史与反馈 |
| 部门负责人 | 普通员工能力，以及所负责部门的聚合统计和任务建议 |
| 管理员 | AI 任务、知识库、建议审核、全局统计、审计、系统设置 |
| 系统管理员 | AI 任务、知识库、建议审核、全局统计、系统设置 |
| 审计员 | 只读 AI 审计日志 |

页面入口仅用于改善体验，服务端仍会对每次请求执行统一权限和部门范围校验。

## 3. 员工工作台

1. 从“全部助手”搜索任务，或从首页的收藏和最近使用进入。
2. 填写动态表单。设备草稿只保存在当前用户的本机加密存储中。
3. 检测到敏感信息时，确认对话框只显示脱敏预览；确认后才能调用本地模型。
4. 生成结果必须人工复核。可复制、重新生成、反馈或在历史记录中删除。
5. 本地模型生成完成但服务端暂时不可用时，结果进入待同步队列，网络恢复后自动同步。

启动页的“查看本机草稿”会打开本机草稿与待同步状态面板；在确认统一登录身份前只显示隔离与同步状态说明，不展示任何用户内容。

个人模型 API Key 只进入系统钥匙串和本地 Tauri 模型进程，不会提交到业务 API、日志或审计元数据。

## 4. 部门负责人

“部门数据”仅聚合负责部门的状态、任务、时间和反馈元数据，不读取生成正文。“提交建议”的部门选择器只包含当前账号负责的部门。

建议类型为常用任务调整或 Prompt 调整。管理员批准只记录审核决定，不会直接修改任务或发布 Prompt。

## 5. 治理中心

- **任务管理**：创建草稿、维护八类动态字段、绑定 Prompt Center 已发布版本、激活或停用任务。只有从未激活且没有生成记录的草稿可物理删除。
- **知识库**：维护分类、标签、关键词、任务关联和优先级。正文加密保存，元数据列表不返回正文；停用后不再参与检索。
- **建议审核**：批准或驳回部门负责人建议。审核状态进入终态后不能再次修改。
- **全局统计**：查看完成率、失败率、部门分布、任务排行、每日趋势和反馈分布。
- **审计日志**：按操作人、动作、对象和日期筛选清洗后的只读元数据。
- **系统设置**：仅能修改安全提示、敏感检测、历史保留、知识上限、默认温度和支持联系人等白名单设置。

用户、组织和应用权限继续在“统一用户管理”维护；Prompt 内容和发布版本继续在“提示词管理中心”维护。桌面端不重复提供用户管理、服务端模型配置或 Prompt 编辑器。

## 6. 应用更新

启动页右下角显示当前版本和更新状态。正式发布构建会在启动页显示后延迟检查一次，并在应用持续运行时定期检查；也可以在启动页点击“检查更新”，或在工作台侧栏点击“检查应用更新”。更新服务地址和更新签名公钥由构建固定，不能通过远程服务地址或用户设置修改。

发现新版本后：

1. 查看新版本号、更新说明和下载大小。
2. 点击“稍后提醒”，本次运行中同一版本在 24 小时内不会再次自动弹出；手动检查仍可立即查看。应用重启后会重新按启动策略检查。
3. 点击“下载并安装”后可查看进度，并可在下载阶段取消。
4. 进入安装阶段后不能取消。签名验证和安装完成后应用会自动重启。

第一版更新会下载由 Tauri 签名验证的完整更新产物，并不是二进制差分补丁；但用户不需要卸载应用或重新手动安装 DMG/MSI。下载、校验或安装失败时，当前版本和本机数据不会被删除，可关闭提示后继续使用并稍后重试。

更新重启后会保留远程服务地址、个人模型配置、系统钥匙串密钥、草稿和待同步队列。

## 7. 设备数据隔离与清理

- 草稿与待同步数据同时按“远程服务 Origin + SSO 用户”隔离；同一台设备上的不同服务器和不同用户互相不可见。
- 更换服务器时，原服务器的待同步数据仍留在原命名空间，不会自动发送给新服务器。
- “查看本机草稿”必须先通过统一登录确认身份，避免其他用户读取本机内容。
- 注销会清理当前服务器、当前用户的草稿，保留该命名空间中的待同步结果和系统钥匙串中的模型密钥；不会影响其他服务器或其他 SSO 用户。
- 旧版本产生且无法确认服务器归属的数据不会自动并入当前服务器，可由用户导出或删除。

## 8. 安全与故障处理

- 遇到 401：重新从统一门户登录。
- 遇到 403：联系管理员核对应用权限、角色或负责部门。
- 激活任务提示 Prompt 未发布：先在 Prompt Center 发布对应版本，再回到治理中心保存。
- 本地模型不可用：检查个人模型地址、模型 ID、钥匙串中的 API Key 和网络连通性。
- 注销会清理当前用户草稿，保留待同步结果和系统钥匙串中的模型密钥，并且不会影响其他 SSO 用户。

审计日志禁止保存 API Key、Cookie、Token、密码、Prompt、输入输出正文或建议正文。
