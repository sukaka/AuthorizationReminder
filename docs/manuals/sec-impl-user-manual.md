# 聚信实施记录系统（Sec-Impl）用户使用手册

## 1. 系统信息
- 前端地址：`http://localhost:8084`
- 后端地址：`http://localhost:5185`
- 系统键：`sec-impl`
- 门户名称：`聚信实施记录系统`
- 系统内标题：`聚信实施记录系统`

本系统用于实施项目全流程管理，强调关键阶段留证和审计防篡改。

## 2. 流程与角色
### 2.1 固定阶段
`INIT -> ASSESS -> IMPLEMENT -> TUNE -> TRIAL -> ACCEPT -> HANDOVER -> CLOSED`

规则：
- 不可跳步。
- 可按规则退回重做。

### 2.2 角色权限
| 角色 | 权限说明 |
|---|---|
| `admin` / `sysadmin` | 可创建实施单、推进阶段、退回、上传附件、配置 SLA |
| `auditor` | 仅可访问审计日志与审计验签菜单 |

说明：当前版本中，审计菜单仅 `auditor` 角色可见。

## 3. 菜单说明
### 3.1 业务角色菜单（admin/sysadmin）
- 看板总览
- SLA催办
- 批量处理
- 实施单列表
- 新建实施单

### 3.2 审计角色菜单（auditor）
- 审计日志
- 审计验签

## 4. 核心操作
### 4.1 新建实施单
1. 进入“新建实施单”。
2. 填写必填项：项目编码、客户名称。
3. 可选填写：产品类型、销售订单号、实施工单号、备注。
4. 提交后进入 `INIT` 阶段。

### 4.2 实施单列表与详情
1. 在“实施单列表”按关键字/阶段筛选。
2. 点击“详情”打开实施详情弹窗。
3. 详情采用可拖动弹窗，便于边看列表边处理单据。

### 4.3 阶段推进
在详情“阶段执行表单”按当前阶段执行下一步：
- `assess`
- `implement`
- `tune`
- `trial`
- `accept`
- `handover`
- `close`

关键校验：
- 移交阶段要求移交编号。
- 归档阶段要求归档责任人和验收单号。

### 4.4 强制留证
推进到以下阶段前，必须先上传当前阶段至少 1 个附件：
- `IMPLEMENT`
- `TUNE`
- `TRIAL`
- `ACCEPT`

操作位置：实施详情弹窗中的“附件上传与留证”。

### 4.5 退回重做
1. 在详情中进入“退回重做”。
2. 选择目标阶段并填写退回原因。
3. 提交后写入时间轴和审计日志。

## 5. SLA 与批量
### 5.1 SLA催办
- 维护阶段 SLA 规则。
- 查看超时实施单和催办记录。

### 5.2 批量处理
- 批量导入实施单（Excel）。
- 批量导出实施单（Excel）。
- 批量阶段推进（实施单 ID + JSON payload）。

## 6. 审计能力
### 6.1 审计日志
- 支持时间、动作、操作人、关键字筛选。
- 日志包含来源 IP。
- 变更信息以中文“变更摘要”展示（新增/移除/字段修改），不直接展示原始 JSON。
- 支持导出审计 CSV。

### 6.2 审计验签
- 支持按 ID 范围执行审计链验签。
- 输出校验条数、问题条数、问题明细。

## 7. 常见问题
### 7.1 为什么看不到审计菜单
请确认当前账号是 `auditor` 角色。

### 7.2 阶段推进失败提示“必须留证”
先为当前阶段上传附件，再执行推进。

### 7.3 批量推进失败
检查实施单 ID、动作与当前阶段是否匹配，以及 payload JSON 格式。
