# 设备流转系统（Device Flow）用户使用手册

## 1. 系统信息
- 前端地址：`http://localhost:18083`
- 后端地址：`http://localhost:5184`
- 系统键：`device-flow`

系统用于管理设备从收货到发货的标准化流程，并提供可验签审计链。

## 2. 流程与角色
### 2.1 固定阶段
`CREATED -> RECEIVED -> HARDWARE_CHECKED -> OS_INSTALLED -> TESTED -> APPROVED -> PACKED -> SHIPPED`

规则：
- 不可跳步。
- 可退回到历史阶段重做。

### 2.2 角色权限
| 角色 | 权限说明 |
|---|---|
| `admin` / `sysadmin` | 可创建流转单、推进阶段、退回、上传附件、配置 SLA |
| `auditor` | 仅审计相关菜单（审计日志、审计验签） |

## 3. 菜单说明
- 看板总览
- SLA催办
- 批量处理
- 流转单列表
- 新建流转单
- 审计日志
- 审计验签

`auditor` 登录后只显示审计相关菜单。

## 4. 核心操作
### 4.1 新建流转单
1. 进入“新建流转单”。
2. 填写必填项：设备 SN、客户名称。
3. 可选填写：销售订单号、来件快递单号、备注。
4. 提交后进入 `CREATED` 阶段。

### 4.2 列表查询与详情
1. 在“流转单列表”按关键字/阶段筛选。
2. 点击“详情”打开流转详情弹窗。
3. 详情为可拖动弹窗，可在不离开列表的情况下处理流程。

### 4.3 阶段推进
在“阶段执行表单”按当前阶段执行下一步动作：
- `receive`
- `hardware-check`
- `os-install`
- `test`
- `approve`
- `pack`
- `ship`

关键校验：
- 装箱阶段要求箱号。
- 发货阶段要求物流公司、发货快递单号。

### 4.4 附件留证（关键）
- 在详情“附件上传与留证”上传文件并绑定阶段。
- 推进到 `HARDWARE_CHECKED` 和 `TESTED` 前，必须先上传该阶段至少 1 个附件。
- 删除附件时，系统会阻止删除“该阶段最后一个必留证附件”。

### 4.5 退回重做
1. 在详情页选择“退回重做”。
2. 选择退回目标阶段并填写退回原因。
3. 提交后记录在时间轴与审计日志中。

## 5. SLA 与批量
### 5.1 SLA催办
- 维护各阶段 SLA 规则。
- 查看超时流转单和催办记录。

### 5.2 批量处理
- 批量导入：Excel 导入流转单。
- 批量导出：导出流转单 Excel。
- 批量推进：输入流转单 ID 列表 + 阶段 payload JSON 后执行。

## 6. 审计能力
### 6.1 审计日志
- 支持按时间、动作、用户、关键字筛选。
- 日志包含来源 IP。
- 变更信息以中文“变更摘要”展示（新增/移除/字段修改），不直接展示原始 JSON。
- 支持审计报表导出。

### 6.2 审计验签
- 执行审计链校验，查看问题数与异常记录 ID。
- 可用于定位篡改或链路断裂。

## 7. 常见问题
### 7.1 推进阶段时报“必须先上传附件”
先在当前阶段上传至少 1 个附件，再推进。

### 7.2 auditor 看不到业务菜单
这是设计行为。`auditor` 仅允许审计功能。

### 7.3 批量推进失败
检查：
1. 流转单 ID 是否存在。
2. 动作是否与当前阶段匹配。
3. payload JSON 是否是合法 JSON。
