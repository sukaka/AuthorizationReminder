# 复签人用户名搜索设计

## 目标

将“指定复签人”的原生下拉框改为可搜索下拉框，用户可输入完整或部分用户名快速定位复签人。

## 交互

1. 输入框获得焦点时展开全部可选用户。
2. 输入用户名后按包含关系实时过滤，不区分英文字母大小写。
3. 结果项显示用户名、中文角色和部门，搜索仅匹配用户名。
4. 点击结果或按回车确认选择，保存对应用户 ID。
5. 支持上下方向键移动焦点、Esc 关闭下拉。
6. 无结果时显示“未找到用户”。
7. 已生成双签令牌或用户目录加载中时保持禁用。

## 边界

- 当前登录用户继续不出现在候选列表中。
- 不搜索手机号、角色或部门。
- 不新增第三方组件依赖，不修改后端用户目录接口。

## 验证

- 源码回归测试验证搜索组件、用户名过滤和空结果文案。
- 前端 Docker 构建验证生产编译。
- 浏览器验证输入部分用户名后结果收窄且可选择。
