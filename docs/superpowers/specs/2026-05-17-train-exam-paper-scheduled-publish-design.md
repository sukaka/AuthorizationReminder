# 培训考试试卷定时发布设计

## 目标

在培训考试系统的试卷管理中，管理员/试卷发布角色可以选择未来日期和时间，让试卷到点自动发布。到点前学员端不可见，不可开始考试；到点后无需人工操作，系统在访问试卷列表或开始考试时自动激活发布。

## 范围

- 后端新增 `scheduled` 试卷状态和 `scheduled_publish_at` 字段。
- 保留现有“立即发布”能力，新增“定时发布/调整时间/取消计划”能力。
- 管理端列表显示计划发布时间；学员端只显示已经真正发布的试卷。
- 到点发布通过请求触发的轻量激活实现，不新增独立定时任务进程。

## 行为

- 定时发布接口接收本地日期时间，按 Asia/Shanghai 转成 UTC 存储。
- 定时发布时间必须晚于当前时间。
- 草稿或已计划试卷可以设置/调整定时发布。
- 归档会清空定时发布时间。
- 访问试卷列表、试卷详情或开始考试前会激活已到点计划：`scheduled -> published`，`published_at = scheduled_publish_at`。

## 测试

- 后端单测覆盖日期时间转换、过去时间拒绝、到点判断。
- 前端源测试覆盖定时发布弹窗、接口调用和列表状态文案。
- 保留现有发布、归档和考试开始流程测试。
