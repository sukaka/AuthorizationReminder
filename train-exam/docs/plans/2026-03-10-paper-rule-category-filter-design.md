# 随机试卷题库分类筛选设计

**目标**

在创建随机试卷时，支持按题库分类筛选题目；每条抽题规则可选择一个或多个题库分类，满足单选和多选场景。

**范围**

- 仅扩展随机组卷规则，不调整题库分类本身的数据模型。
- 分类筛选基于现有题库分类名称。
- 固定试卷、题库管理、考试作答逻辑不改。

**方案**

1. 后端为 `te_paper_question_rules` 增加 `question_categories_json` 字段，用 JSON 数组保存分类名称列表。
2. 试卷创建/读取时在规则对象中收发 `question_categories` 数组。
3. 随机抽题时在原有 `status / question_type / difficulty / tags` 基础上追加 `question_category IN (...)` 过滤。
4. 前端创建试卷表单中为每条规则增加“题库分类”多选框，数据来源于现有题库分类接口。

**取舍**

- 不引入规则分类关联表，避免这次需求把随机组卷结构复杂化。
- 不拆成“单选分类”和“多选分类”两套控件，统一多选更简洁；选 1 个即单选。

**验证**

- 单元测试覆盖规则分类归一化，确保支持空值、单选、多选、去重。
- 本地构建并重建 `train-exam-api`、`web-train-exam` 镜像。
