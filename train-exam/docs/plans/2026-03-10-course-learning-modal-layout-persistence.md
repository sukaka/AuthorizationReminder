# 课程学习弹窗布局记忆

## 目标

让课程学习弹窗在关闭后再次打开时，自动恢复用户上次调整过的位置和尺寸。

## 方案

- 使用浏览器 `localStorage` 保存课程学习弹窗布局
- 保存内容包括：
  - 普通窗口的 `left/top/width/height`
  - 是否处于铺满窗口状态
  - 铺满前的 `restoreRect`
- 初始化时优先读取本地布局；若无记录则回退到默认窗口尺寸
- 拖拽或缩放进行中不写入，待交互结束后再持久化，减少无意义写入

## 边界

- 布局恢复前仍通过现有 `clampCourseLearningModalRect` 限制在当前视口内
- 不引入后端存储，不与用户账号绑定
