# 题目批量发布与一键发布设计

**目标**

在题目列表中支持两种发布方式：

1. 发布选中的题目
2. 一键发布当前筛选条件下的所有草稿题

**范围**

- 保留现有单条审核接口和驳回能力。
- 新增批量发布能力，不改题目导入、题库分类、试卷逻辑。
- 一键发布仅处理当前筛选结果中的 `draft` 题目。

**方案**

1. 后端抽离题目筛选工具，统一生成列表查询和批量发布用的筛选条件。
2. 新增批量发布接口，支持两种入参：
   - `question_ids`
   - `filters`
3. 前端在题目列表头部增加：
   - `发布选中(N)`
   - `一键发布当前筛选草稿`
4. 单条草稿题操作按钮由“通过”改为“发布”，仍走现有审核发布逻辑。

**规则**

- 只有管理员/审核员可发布。
- 批量发布时仅真正发布 `draft` 状态题目。
- 已发布或已归档题目计入跳过，不重复发布。
- 发布完成后刷新题目列表、题库分类统计和概览。

**验证**

- 单元测试覆盖题目筛选条件构造。
- 本地跑后端测试和前端构建。
- 重建 `train-exam-api` 与 `web-train-exam` 镜像并核验服务状态。
