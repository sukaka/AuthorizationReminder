# 课程学习路径弹窗化设计

## 背景

当前“培训管理”页同时展示课程列表和“学习路径与章节完成度”内联面板。用户要求将学习路径改为弹窗展示，并在课程列表中通过“查看课程”按钮进入。

## 目标

- 课程列表每行提供“查看课程”入口
- 点击后以弹窗展示当前课程的学习路径、章节完成度和课程进度汇总
- 页面内联的“学习路径与章节完成度”面板移除
- 保留现有学习进度、文档预览、视频播放器、资源编辑/删除逻辑

## 方案

1. 在 `App.jsx` 新增课程学习弹窗状态与打开/关闭处理函数。
2. 复用现有 `fetchLearningPath`、`fetchMyLearningProgress` 和章节表格 JSX，不改接口协议。
3. 课程列表新增“操作”列：
   - 普通用户显示“查看课程”
   - 可写角色显示“删除课程”与“查看课程”
4. 使用现有 `modal-mask` / `modal-card` 样式体系，新增课程学习弹窗宽度和内容间距样式。

## 风险与约束

- 前端当前没有现成测试框架，本次先用生产构建验证 UI 改动不破坏编译。
- 学习路径中的文档预览和视频播放器依旧通过现有独立弹窗打开，课程学习弹窗只作为上层容器。
