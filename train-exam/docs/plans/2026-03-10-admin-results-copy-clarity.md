# 管理员结果中心文案澄清方案

## 目标

把“个人成绩页”语气改成“管理员结果审阅中心”语气，让管理员第一次看到时就知道：

- 这是查结果的地方
- 可以按考生和试卷筛选
- 可以打开单次考试卷面
- 可以查看某个考生的历史考试记录

## 文案原则

- 先说用户要完成什么，不先说系统状态
- 用“结果、卷面、考生记录”这些业务词，少用“历史考卷、成绩证书”这种个人语境词
- 按钮用动作名，不用模糊词
- 错误提示同时告诉用户下一步该做什么

## 术语统一

- `成绩`：
  用在分数数字本身
- `考试结果`：
  用在列表、筛选、管理入口
- `卷面详情`：
  用在单次考试的详细页面或弹窗
- `考生记录`：
  用在某个考生的多次考试历史

不要混用：

- `历史考卷`
- `成绩证书`
- `切换到历史考卷`

这些词更像个人使用语境，不适合管理员视角。

## 确认弹窗文案

### 查看历史卷面前存在进行中的考试

- 当前：`当前考试仍在进行中，切换查看历史考卷将离开当前答题视图，是否继续？`
- 建议：`当前考试还在进行中。现在去看卷面详情，会离开答题页面。是否继续？`

原因：

- 更短
- 先说当前状态，再说后果
- “卷面详情”比“历史考卷”更容易理解

## 推荐最终成套文案

### 管理员态

- 菜单：`考试结果`
- 页面标题：`考试结果`
- 页面说明：`按考生、试卷和时间筛选结果，查看卷面详情与考生记录。`
- 列表主按钮：`查看卷面`
- 列表次按钮：`查看考生记录`
- 空状态：`还没有可查看的考试结果`

### 普通用户态

- 菜单：`成绩与证书`
- 页面标题：`成绩与证书`
- 页面说明：`查看你的考试成绩、历史记录和证书。`
- 历史按钮：`查看卷面详情`

## 一句话总结

把这块文案从“我怎么看自己的历史考试”改成“管理员怎么查结果、看卷面、追踪考生记录”。
