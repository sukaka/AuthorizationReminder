# 2026-07-17 聚信 AI 助手 4.0 正式编辑器实现记录

## 本次目标

落实并重新整理 4.0 正式成果编辑器方案：正式入口收敛到成果中心，单编辑租约是编辑前置条件，租约失败或失效时只读；在线编辑器不是独立 Demo，也不是 Office 容器。

## 约束

- 不做实时多人协同，不新增 Office/OnlyOffice 容器。
- 不改真实生产数据、密钥、部署配置或版本号。
- 保留当前用户工作区中与本任务无关的未提交改动。

## 验收记录

- 正式入口：从 `App.tsx` 移除独立“4.0 编辑 Demo”菜单和路由，仅保留成果中心上下文中的正式编辑器。
- 编辑权：成果详情加载时先获取单编辑租约；第二个用户收到 `409 DELIVERABLE_EDIT_LEASE_CONFLICT`，页面只读并显示占用者/预计释放时间；心跳失败、切换成果或卸载页面时停止编辑并释放租约。
- 保存链路：草稿自动保存和不可变版本提交均携带 fencing token；保存前再次校验编辑权，成功后释放租约。
- 视觉：正式成果页主色已从旧青绿色收敛到最终黑/蓝方案（深色文字、蓝色操作色、浅灰画布、白色纸张、金色提示变量）。
- 拖拽：顶层块拖动按目标块上半/下半区计算 before/after 落点，渲染蓝色插入线并在 drop 后保持块 ID；段落、表格、图片均覆盖回归。
- 图片导入：编辑器外层上传区支持拖入 `image/*`，复用现有媒体上传服务；非图片文件不触发上传。
- 图片属性：图片块支持替代文本、宽度（40–1200px）和左/中/右对齐；规范化写入 `attrs`，同时同步旧顶层 `alt`，保留其他媒体元数据。
- 图片恢复：上传状态使用真实的不确定处理中提示，不伪造百分比；失败会保留原始 `File` 并显示“重试图片上传”，重试成功后只插入一次媒体块。
- 事实锚点：目录和审阅定位会滚动到真实 `[data-block-id]` 区块、聚焦并短暂高亮；隐藏 textarea 仅作兼容镜像和文本范围回退。
- 表格：适配层和编辑器已有增删行列、列宽调整、相邻单元格横向/纵向合并与拆分；纵向操作限制为规则网格中的单跨度相邻单元格，避免静默破坏复杂跨行/跨列结构。
- 表格键盘：表格单元格支持左右/上下方向键以及 Home/End 在网格内移动焦点，并通过组件回归覆盖。
- 删除保护：块操作区提供统一删除入口；删除前按事实、审阅问题、评论统计锚点影响并要求确认，删除只修改当前草稿。
- 输入与无障碍：中文 IME 合成期间不提前提交中间态；粘贴统一转为纯文本并清理控制字符；编辑区提供区块键盘移动说明和 `aria-keyshortcuts`。
- 兼容：旧正文 `textarea` 改为隐藏兼容镜像，结构化块编辑器是唯一可见编辑区，避免用户看到两个编辑器。
- 性能：新增 500 个区块、超过 5 万字的归一化/纯文本提取/重排本地基准，单次编辑变换预算为 1 秒内。
- 测试：`npm run typecheck` 通过；桌面端 `npm test -- --run` 为 41 个测试文件、318 个测试全部通过；服务端租约定向测试为 2 passed、32 deselected；`git diff --check` 通过。全量桌面测试有既有 MSW 未处理请求警告与 jsdom 导航提示，但退出码为 0。
