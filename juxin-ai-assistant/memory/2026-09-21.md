# 2026-09-21

## 客服系统 API

- 为聚信 AI 助手新增签名客服接入：`POST /api/ai/customer-service/v1/messages` 与状态查询接口。
- 接口默认关闭，使用分接入方 HMAC-SHA256 凭据和时间窗口鉴权。
- 外部问答只检索已审核且允许外部公开的正式知识；无依据或模型回答不安全时自动创建人工工单。
- 问题和回答加密落库；客户、会话和外部消息编号仅保存带密钥摘要；同一消息支持持久化幂等重放。
- 新增 Alembic 迁移 `0072_external_answer_cipher`，并将配置接入 HTTPS Compose 覆盖文件。
- 接入说明：`docs/customer-service-api.md`；实施与验证记录：`docs/plans/2026-09-21-customer-service-agent-api.md`。
