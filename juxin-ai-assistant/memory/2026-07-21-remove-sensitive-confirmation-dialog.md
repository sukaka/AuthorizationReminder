# 2026-07-21 移除敏感信息确认弹窗

## 用户目标

删除发送内容时反复出现的“检测到敏感信息”弹窗，使复制粘贴和直接输入都能立即发送。

## 已确认原因

- 聊天页和专业任务页都会在服务端返回 `SENSITIVE_CONFIRMATION_REQUIRED` 后展示同一个确认弹窗。
- 服务端在聊天准备和专业任务准备阶段对输入做敏感扫描，并要求携带确认摘要后二次提交。
- 该机制容易对正常工作内容产生误报，造成每次发送额外操作。

## 实施边界

- 去掉聊天和专业任务的交互式敏感确认，不改变其他聊天、任务和模型路由逻辑。
- 保留日志脱敏、密钥长期记忆保护等非交互式安全机制。
- 本次不升级版本、不提交或推送；是否发布由用户后续决定。

## 当前状态

- 已移除前端确认弹窗和后端 409 确认阻断；旧客户端携带确认摘要字段仍兼容。
- 验证通过：后端定向测试 63 项；桌面端定向测试 74 项；桌面端类型检查通过；差异格式检查通过。
- 保留日志脱敏、密钥保护和长期记忆敏感信息保护。未提交、未推送。
