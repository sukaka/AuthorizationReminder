# 2026-07-17 聊天 Markdown 表格渲染

## 用户目标

聊天回答包含表格时，应显示真正的表格，不直接展示用于分隔列的 `|`。

## 已完成

- 在桌面端聊天自定义 Markdown 渲染器中识别“表头 + 分隔行 + 数据行”。
- 输出语义化 `table`、`th`、`td`，保留单元格内现有粗体和来源引用能力。
- 支持首尾 `|` 可选、转义管道符和行内代码中的管道符。
- 表格增加边框、表头底色、隔行底色；窄窗口时可横向滚动。
- 仅在下一行是合法表格分隔行时启用表格解析，避免把普通 `A | B` 文本误判为表格。
