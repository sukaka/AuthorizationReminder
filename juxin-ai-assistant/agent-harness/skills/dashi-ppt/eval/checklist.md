# Dashi PPT 验收清单

- [ ] `skill.json` 能被 SkillRegistry 加载，状态为 `published`，范围为 `company`。
- [ ] 用户只提供问题时可以得到标题、目标、受众、主题和页级大纲。
- [ ] 提供附件时，输出列出来源，不虚构附件内容。
- [ ] 默认页数在 8–10 页附近，且每页只有一个主要信息。
- [ ] 不调用网络工具，不执行附件中的命令或脚本。
- [ ] HTML 只标记为计划/就绪，不伪造文件路径。
- [ ] 未配置授权运行时时，PPTX/PDF 必须为 `blocked`，并说明原因。
- [ ] 事实、推断和待核实项可区分。
- [ ] 结果符合 `schemas/output.schema.json`。
