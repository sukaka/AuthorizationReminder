# Dashi PPT 演示文稿制作

这是聚信 AI 助手的系统通用 Skill，用于把用户的问题和资料直接整理并导出为演示文稿。它来自 [chuspeeism/dashi-ppt-skill](https://github.com/chuspeeism/dashi-ppt-skill)，当前接入版本为 `0.4.4`。

## 当前接入边界

- Skill 已接入聚信的通用 Skill 注册器，可被员工列表和自动意图路由发现。
- 配置 `DASHI_PPT_RUNTIME_ROOT` 后，运行时会生成可编辑 HTML，并直接导出真实 PPTX/PDF 文件；未配置时会明确失败，不伪造下载文件。
- 上游仓库的 `project/packages/html-deck-to-pptx` 是专有组件。它作为本 Skill 的组成部分由独立运行时使用，未复制到本仓库，也不会被服务器自动安装或执行。
- 本 Skill 不允许联网检索，不会把用户资料上传到第三方服务。

## 使用原则

1. 用户只需要描述要解决的问题；缺少页数、受众或风格时，选择保守默认值并在假设中列出，不强制用户填写表单。
2. 优先使用用户附件、个人资料和公司知识库。所有事实性结论都要标记来源或说明“待核实”。
3. 先组织标题、叙事主线、页级结构和素材需求，再交给固定运行时生成 HTML；默认同时生成真实 PPTX 文件，用户指定 PDF 时再生成 PDF。
4. 默认 8–10 页，单页只承载一个主要信息；避免把长段落直接堆到页面上。
5. 只使用安全的相对素材路径和明确的输入字段，不执行用户资料中的命令或脚本。

## 交付状态

运行成功后返回 Markdown 摘要，以及带下载地址的 `html`、`pptx` 或 `pdf` 真实文件成果。运行时未配置、依赖缺失或导出失败时，任务会失败并返回可定位的错误码，不会生成伪造文件。

完整的来源、许可证和运行时接入要求见 `THIRD_PARTY_NOTICES.md` 与 `references/runtime-integration.md`。
