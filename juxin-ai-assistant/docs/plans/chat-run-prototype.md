# 聊天 Run 交互原型

## 目标

做一个不接真实后端的聊天交互原型，验证统一 Run、执行活动、Steer/Queue 和上下文侧栏的布局是否符合聚信 AI 助手的使用习惯。

## 范围

- 新增独立的聊天原型页面，可通过 `?prototype=chat` 打开，预览入口不依赖真实登录服务。
- 使用现有主题变量和聚信红色品牌标识，不改变真实聊天页面。
- 使用本地状态模拟运行中、停止、补充任务、排队消息和侧栏切换。

## 不包含

- 不调用真实聊天接口、Run API 或模型。
- 不修改数据库、版本号、生产配置。
- 不提交或推送 Git。

## 验证命令

```bash
cd apps/desktop
npm run typecheck
npm run build
```
