# 当前聊天临时附件修正方案

## 目标

- “仅用于当前聊天”的文件可在新聊天中直接上传，不再要求先发送消息或开启工作任务。
- 临时附件只绑定当前聊天，不进入“我的资料”或公司知识库。
- 聊天进入回收站时保留附件以支持恢复；永久删除聊天时同步删除附件记录和受控存储目录内的原文件。
- 上传弹窗文案明确表达上述生命周期，并避免重复格式提示。

## 范围

- 后端增加创建空聊天的受权接口，供首次上传临时附件时使用。
- 桌面端在当前聊天尚未落库时自动创建聊天，再上传临时附件。
- 永久删除聊天时，仅清理该用户、该聊天、`session_attachment` 类型的资料及其分块。
- 更新前后端测试；5.0 分支保持现有版本号不变，并按后续授权提交、推送。
- 以 AI 助手 1.1.2 为基线建立 1.2.0 分支，兼容移植本次上传体验与当前聊天临时附件能力。

## 完成记录

- 增加空白聊天创建接口；用户选择“仅用于当前聊天”后，桌面端会自动创建并立即绑定该聊天，无需先发送一条消息。
- 第一次真正提问时，“新聊天”标题会按问题自动更新。
- 临时附件按 `conversation_id` 隔离，不进入个人资料或公司知识库；软删除聊天时保留，永久删除时同步清理分块、索引和受控目录中的原文件。
- 上传弹窗改为“仅用于当前聊天”，并明确永久删除聊天后才清理附件。
- 验证通过：后端聊天 API 38/38，桌面端聊天页 54/54，TypeScript 类型检查和 `git diff --check` 通过。
- 按用户要求，5.0 分支保持当前版本号；后续已授权提交并推送 5.0，同时移植并发布 1.2.0 分支。
