# 1.0 分支移植 Markdown 表格渲染计划

## 目标

将已验证的 Markdown 表格语义化渲染能力移植到 `codex/ai-assistant-1.0`，以 1.1.2 作为代码基线，保持版本号不变。

## 范围

- 识别标准 Markdown 表头、分隔行和数据行。
- 渲染为带表头和单元格语义的 HTML 表格。
- 为窄窗口增加横向滚动和基础视觉样式。
- 增加回归测试，确保普通包含 `|` 的文本不被误判为表格。

## 发布约定

本次按参考会话的 1.0 分支做法，只创建并推送 `codex/ai-assistant-1.0`，不在该分支内修改 `VERSION` 或桌面端包版本；提交消息使用当前基线版本标记 `ai-assistant-v1.1.2`。
