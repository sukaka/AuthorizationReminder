# 系统切换菜单遮挡修复计划

## 目标

修复 AI 助手 Web 端点击“切换”后系统列表被侧栏右边界裁剪、无法完整查看和点击的问题。

## 根因与范围

- `.sidebar` 使用 `overflow: hidden`，会裁剪绝对定位的系统切换菜单。
- 菜单当前以 `left: 0` 对齐切换按钮，在侧栏底部靠右时会向侧栏外展开。
- 本次只调整桌面端应用壳层的系统切换菜单样式，不改系统切换接口、权限逻辑和其他业务页面。

## 实施方案

1. 让菜单右侧与切换器对齐，避免常规窗口下横向越过侧栏。
2. 让侧栏允许浮层溢出并提升层级，避免菜单被侧栏或主内容区遮挡。
3. 为系统列表增加视口相关的最大高度和纵向滚动。
4. 增加 CSS 回归断言，覆盖定位、层级和滚动行为。

## 验收标准

- Web 端点击“切换”后，系统列表完整显示，系统名称和链接可点击。
- 侧栏宽度较小或系统数量较多时，菜单不会被边界裁剪，超出高度时可滚动。
- 不影响桌面运行时隐藏系统切换器的行为。

## 验证命令

- `npm test -- --run tests/proxy-config.test.ts`
- `npm run typecheck`
- `git diff --check`

## 结果

已完成：

- 侧栏改为允许浮层溢出，并设置层级，系统菜单不会再被侧栏边界或主内容区盖住。
- 系统菜单改为右侧对齐，避免从侧栏底部向右展开造成横向裁剪。
- 系统列表增加最大高度和纵向滚动，系统较多时仍可访问全部选项。
- 增加 `proxy-config.test.ts` 中的 CSS 回归断言。

验证结果：

- `npm run typecheck`：通过。
