# 2026-07-26 登录后强制先选系统

## 背景

当前聚信 AI 助手在多个登录入口把统一登录门户固定为 `system=ai-assistant`，导致用户完成认证后会直接进入 AI 助手，而不是先看到自己有权限的系统列表。

## 目标

- admin 和普通用户统一先进入系统选择页；
- 只展示统一登录平台判定为当前账号可访问的系统；
- 已登录后的“切换系统”能力保留，仍然可以定向跳转到指定系统。

## 实施范围

1. 桌面端 bootstrap 返回的 `authPortalUrl` 默认改为 `/portal`；
2. Web 端默认登录入口与 401 重登录入口默认改为 `/portal`；
3. 手动切换系统时继续通过 `system=<key>` 指向目标系统；
4. 更新对应前后端测试。

## 文案补充

- 登录页明确提示“统一登录后请选择要进入的系统”，降低用户误以为会自动直达某个业务系统的概率。
- 选择系统页需要把“先登录、再选系统、再进入工作台”的顺序讲清楚，避免 admin 和普通用户误以为登录后会自动进入某个默认系统。

## 2026-07-26 UI 补充

1. 桌面端启动页补充 3 步引导：
   - 填写服务地址；
   - 使用统一登录；
   - 选择要进入的系统。
2. Web 普通登录态提示同步调整为“统一登录后请选择系统”；
3. 未登录或 401 重登时统一回到 `/portal`，不再默认拼接 `system=reminder` 或 `system=ai-assistant`；
4. 仅在用户主动切换系统时，才带 `system=<key>` 定向进入目标系统。

## 风险控制

- 不新增新接口，不修改统一登录平台鉴权协议；
- 不改变已登录后会话结构；
- 不改“切换系统”菜单，降低对现有导航的影响。
