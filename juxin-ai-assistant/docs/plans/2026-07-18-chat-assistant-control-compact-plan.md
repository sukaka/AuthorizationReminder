# 聊天助手控件紧凑化方案

## 目标

聊天顶部默认控件只展示“自动路由”四个字，减少视觉占用，避免背景框压到聊天窗口；手动切换入口继续保留。

## 计划

- 删除“助手”和“发送问题后自动识别”两段辅助文案。
- 删除默认状态图标，缩小控件内边距和最小宽度。
- 保持“切换助手”按钮、自动路由结果和手动助手列表功能不变。
- 更新测试并运行聊天页测试、类型检查、差异检查。

## 验收标准

- 默认状态可见文本为“自动路由”和“切换助手”。
- 点击“切换助手”仍可展开并选择手动助手。
- 自动路由请求和手动模式请求契约不变。

## 执行结果

- 已移除图标、“助手”和“发送问题后自动识别”文案，默认控件只显示“自动路由”。
- 已压缩控件的高度、间距和宽度，避免顶部背景框侵入聊天内容区。
- 已保留路由原因为“自动路由”文本的无障碍 `title`，不再占用可视布局。
- 已更新自动路由测试，验证辅助文案不再渲染且自动路由/手动助手入口仍可用。
