# V1.10 提示词手册导入、任务页改版与 Word 导出设计

## 1. 背景与目标

本设计以《聚信得仁公司级 AI 提示词手册_统一格式版_V1.10》为权威业务来源，完成三项改造：

1. 调整任务执行页布局，扩大输出预览区域。
2. 将手册中的可执行 Prompt 合并导入现有助手目录。
3. 为生成结果提供手动 Word 下载，并严格应用手册约定的公司级统一文档格式。

本次改造不删除手册未覆盖的现有任务，不破坏历史生成记录、收藏关系或使用统计。

## 2. 已确认的产品决策

- 任务页采用“顶部任务信息 + 下方 43/57 双栏”布局。
- 只将可直接执行的 Prompt 做成可点击任务。
- 知识说明和术语规范作为共享知识自动参与生成。
- 检查清单默认作为质量规则；具有独立使用价值的检查场景保留为任务。
- 现有 88 个任务与手册任务合并去重。
- 同一助手内名称重复时，以 V1.10 的 Prompt 正文和规则为准。
- Word 由服务端生成，用户点击按钮后手动下载。

## 3. 范围

### 3.1 纳入范围

- 销售、售前、产品交付与实施、软件测试、行政人力、商务投标、渗透测试与安全服务相关可执行 Prompt。
- 公司知识、产品矩阵、官网口径、术语规范和安全边界。
- 正式文档统一输出总控模块。
- 任务目录、Prompt Center 内容、任务字段和 Prompt 绑定的同步。
- 生成结果 Word 导出、权限校验和审计。

### 3.2 不纳入范围

- 运行时直接读取用户上传的 Word 手册。
- 把说明性章节全部做成任务。
- 自动下载 Word 或生成后自动弹出保存窗口。
- 删除手册未覆盖的现有通用、文档生成或培训考试任务。
- 在本次改造中建设通用富文本编辑器或在线 Word 编辑器。

## 4. 任务页布局

任务执行页改为两层结构：

1. 顶部任务摘要条：任务名称、说明、安全提示。
2. 主体双栏：
   - 左侧填写区约占 43%。
   - 右侧输出预览区约占 57%。

输出区支持长内容滚动，保留复制、重新生成和反馈操作。生成完成后增加“导出 Word”按钮。窄屏继续切换为单列布局，顺序为任务摘要、填写区、输出区。

## 5. 手册解析与结构化清单

### 5.1 离线编译

新增离线编译工具，将 V1.10 DOCX 解析为可审查的结构化清单。运行时系统不依赖原始 Word 文件。

每个候选条目记录：

- 手册版本和来源章节。
- 所属助手和业务分类。
- 原始标题、规范化名称和稳定任务代码。
- 适用场景和使用提示。
- Prompt 正文。
- 动态输入字段。
- 输出文档类型。
- 是否属于正式文档。
- 风险规则和人工复核要求。
- 导入决策：新增、升级、保留、排除或待确认。
- 排除或待确认原因。

### 5.2 条目分类

条目分为四类：

1. 可执行 Prompt：创建或升级任务。
2. 公司知识与术语：导入共享知识库。
3. 质量检查规则：自动附加到对应任务。
4. 说明性内容：保留在导入报告中，不创建任务。

标书风险自查、文档交付检查、测试用例质量检查等可独立使用的检查项归入可执行 Prompt。

## 6. 任务合并规则

### 6.1 匹配顺序

任务按以下顺序匹配：

1. 已存在的稳定任务代码。
2. 同一助手内的规范化任务名称。
3. 明确维护的别名映射。

规范化名称仅去除编号、空白差异及“Prompt”“提示词”“生成”等无区分度后缀，不进行模糊语义自动覆盖。

### 6.2 重复任务

匹配成功时：

- 保留现有任务 UUID、代码、历史记录、收藏和使用统计。
- 任务名称可按 V1.10 标准名称校正。
- Prompt 正文、字段、输出类型、安全提示和来源信息以 V1.10 为准。
- Prompt Center 在原 Prompt ID 上创建并发布新版本。

不同助手下的同名任务分别保留。名称相近但业务用途不同的任务不自动合并，进入人工确认清单。

### 6.3 新任务与旧任务

- 手册新增任务使用新的稳定任务代码和 Prompt ID。
- 手册未覆盖的旧任务继续保留。
- 新增售前助手和软件测试助手。
- 现有技术与安全服务助手承载渗透测试、安全服务和代码审计类任务。

## 7. Prompt、知识与总控规则

### 7.1 Prompt Center

结构化清单是 Prompt 内容的唯一导入源。导入器按稳定映射更新 Prompt Center：

- 已有任务在原 Prompt ID 上创建新版本并发布。
- 新任务创建新 Prompt、发布并写回绑定信息。
- 每个 Prompt 保存来源标识，例如“V1.10｜第四部分｜客户拜访”。

### 7.2 共享知识

公司知识、产品术语、官网口径和部门规范使用现有知识库及任务关联表导入：

- 公司级知识关联所有相关任务。
- 部门知识只关联对应部门任务。
- 产品专项知识只关联相应产品或服务任务。

### 7.3 统一输出总控模块

正式文档任务不在每条 Prompt 中重复复制总控正文。总控模块作为受控系统规则保存，并在生成准备阶段统一追加。

任务清单记录文档类型，例如：

- 方案类。
- 报告类。
- 清单或台账类。
- 会议纪要类。
- 测试文档类。
- 商务或投标文档类。
- 行政人力类。
- 渗透测试或安全服务类。

生成时追加通用总控规则及对应文档类型结构。非正式沟通类任务不强制生成封面、目录或页眉页脚说明。

## 8. 导入流程与一致性

导入分为四个阶段：

1. 编译：解析手册并生成清单。
2. 预检：验证重复名称、Prompt ID 冲突、字段完整性和分类结果。
3. 应用：更新 Prompt Center，再更新助手目录和绑定。
4. 验证：确认所有启用任务均绑定已发布 Prompt。

由于 Prompt Center 和助手服务属于不同存储，无法使用单一数据库事务。采用导入批次和补偿机制：

- 预检未通过时不写入任何系统。
- 每次导入生成唯一批次号和变更清单。
- Prompt Center 先创建草稿版本，全部成功后统一发布。
- 助手目录更新失败时，不切换任务绑定，并将新版本保持为未启用状态。
- 导入器输出可恢复报告，支持按批次重新执行。

导入必须幂等，重复运行不会重复创建任务或 Prompt。

## 9. 服务端 Word 导出

### 9.1 用户流程

1. 用户完成生成。
2. 输出区出现“导出 Word”按钮。
3. 客户端请求当前生成记录的 Word 下载接口。
4. 服务端校验登录用户和记录归属。
5. 服务端解密已保存输出，生成 DOCX 文件流。
6. 浏览器或桌面 WebView 按附件下载。

### 9.2 接口

新增生成记录导出接口，使用生成 UUID 定位记录。接口必须：

- 只允许记录所有者导出。
- 只允许已完成且未删除的记录导出。
- 不接受客户端提交任意待导出的正文。
- 使用安全文件名，例如“任务名称_2026-06-23.docx”。
- 返回 DOCX 文件流，不永久保存导出文件。

### 9.3 Word 模板

服务端模板严格采用手册规范：

- A4 纵向。
- 上下边距 2.5 cm，左右边距 2.8 cm。
- 标题使用《XXX》格式并居中加粗。
- 一级标题使用“一、二、三”，二级标题使用“1. 2. 3.”，三级标题使用“（1）（2）（3）”。
- 正文使用正式中文正文字体和统一行距。
- 表格使用标准表格，表头加粗并应用统一底色。
- 封面包含文档名称、客户或部门、项目或系统、版本、编制单位、编制人员、日期和保密级别。
- 包含修订记录。
- 页眉显示“聚信得仁｜文档名称｜版本号”及品牌细线。
- 页脚显示公司名称、保密说明和页码。
- 文档末尾保留待确认事项、需人工复核事项、不建议直接对外发送内容和下一步动作。

Markdown 标题、段落、列表和表格转换为对应 Word 结构。无法识别的内容按普通正文写入，不丢弃原文。

### 9.4 安全与审计

- 原始生成内容继续使用现有加密存储。
- Word 仅在内存或受控临时文件中生成，响应结束后清理。
- 导出操作写入审计日志，记录用户、生成 UUID、任务 UUID、结果和时间。
- 导出失败不修改生成记录，不影响复制或重新生成。

## 10. 异常处理

- DOCX 解析失败：终止编译并报告具体章节或条目。
- 同名匹配存在歧义：不覆盖，进入待确认列表。
- Prompt ID 冲突：预检失败，不开始导入。
- Prompt 创建、发布或绑定失败：保留原绑定，记录导入批次失败原因。
- 知识关联失败：相关任务不启用新 Prompt 版本。
- Word 生成失败：返回安全错误信息，保留原始生成结果。
- Markdown 格式不规范：尽量转换，无法识别部分作为正文。
- 缺失字段统一使用“待确认”“不涉及”或“暂无”，不虚构内容。

## 11. 测试策略

### 11.1 手册编译与导入

- DOCX 标题、适用场景和 Prompt 正文提取测试。
- 条目分类测试。
- 名称规范化和别名映射测试。
- 现有任务升级并保留 UUID 的测试。
- 新任务创建和重复执行幂等测试。
- Prompt 发布失败时不切换绑定的测试。
- 所有启用任务均绑定已发布 Prompt 的完整性测试。

### 11.2 生成规则

- 正式文档任务自动追加总控模块。
- 非正式沟通任务不追加封面和目录要求。
- 公司知识和部门知识按关联范围注入。

### 11.3 Word 导出

- 所有者可以导出，其他用户返回禁止访问。
- 未完成或已删除记录不可导出。
- DOCX 可正常打开。
- 标题、表格、页眉、页脚、封面和最终检查章节存在。
- 导出产生审计记录。
- 导出失败不影响生成记录。

### 11.4 界面

- 桌面宽度下使用顶部摘要和 43/57 双栏。
- 输出区长文本滚动正常。
- 窄屏切换为单列。
- 仅在生成完成后显示“导出 Word”。
- 下载失败显示明确错误，按钮可重试。

## 12. 验收标准

- 任务页使用已确认的 B 布局，输出区明显宽于填写区。
- 手册中所有可执行 Prompt 均成功导入，或在报告中记录明确排除原因。
- 同一助手内重复名称任务使用 V1.10 正文，同时保留旧 UUID、代码和历史关系。
- 公司知识和术语规范自动参与对应任务生成。
- 正式文档任务统一应用第三部分总控模块。
- 用户可手动下载符合 V1.10 格式的 Word 文件。
- 用户只能导出自己的生成记录。
- 导出行为有审计记录。
- 导入报告包含新增、升级、保留、排除、待确认和失败统计。
