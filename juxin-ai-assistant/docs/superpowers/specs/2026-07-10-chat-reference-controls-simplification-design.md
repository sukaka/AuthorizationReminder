# 聊天资料入口精简设计

## 目标

减少聊天页资料范围控制的重复入口，让用户只在一个位置选择资料范围，并让刚上传的个人资料立即用于当前任务。

## 界面调整

- 保留顶部“参考资料”下拉框，作为资料范围的唯一控制入口。
- 保留输入框内“上传资料”和“引用资料”；前者上传文件，后者选择具体个人资料文件。
- 删除输入框内“查公司知识”“我的资料”“当前附件”三个范围快捷按钮。
- 删除输入框内仅用于回显当前助手模式的胶囊。
- 保留顶部“助手模式”下拉框；它继续控制任务能力，与资料范围职责分离。

## 上传行为

- “仅用于当前任务”上传成功后，继续自动启用该附件。
- “保存到我的资料”上传成功且文件可引用时，自动选中该文件，将助手模式切换为“查公司知识”，并把资料范围切换为包含“我的资料”的对应组合。
- “提交管理员审核”上传成功后不自动引用。
- 若上传结果尚未达到可引用状态，只保存文件并显示状态，不创建无效引用。

## 验收标准

- 输入框不再展示三个资料范围快捷按钮及助手模式回显。
- 顶部“参考资料”下拉框仍可选择全部四种资料组合。
- 保存到“我的资料”的可引用文件上传成功后，当前任务请求包含该文件，并启用个人资料范围。
- 当前任务附件、具体资料选择、管理员审核等原有流程不回归。

## 测试

- 更新聊天页组件测试，先验证旧行为与新要求冲突。
- 覆盖重复控件移除、上传后自动选择、请求参数传递。
- 运行聊天页定向测试、前端类型检查和浏览器截图检查。
