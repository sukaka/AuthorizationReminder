# 上传分类层级与非空界面设计规格

## 目标

资料上传时清楚区分一级、二级分类；应用在加载、空数据、失败、无权限和未知页面状态下始终显示可理解、可恢复的界面，不出现纯白或只有页面外壳的情况。

## 范围

- 知识库页面的资料上传表单。
- 聊天页面的资料上传弹窗。
- 桌面端应用级未知页面和渲染异常兜底。
- 本次不实现自定义树形弹层，不改变分类后端数据结构和上传接口。

## 分类选择设计

采用共享的层级分类选项构造逻辑，输入现有 `KnowledgeCategoryPayload[]`，输出按排序值和名称稳定排序的目录项。

- 一级分类显示：`产品资料`
- 二级分类显示：`　└ WDSP`
- 更深层级继续缩进：`　　└ 子分类`
- 二级分类保留自身名称作为提交值，避免修改现有接口契约。
- 选中二级分类后，在控件附近显示完整路径，例如 `当前分类：产品资料 / WDSP`。
- 停用分类不出现在上传选择中。
- 没有可用分类时，显示“暂无可用资料分类，请联系管理员在字典管理中创建或启用分类”，并禁用上传确认按钮。

知识库上传页与聊天上传弹窗必须复用同一套层级构造和标签规则，避免两个入口行为漂移。

## 非空界面规则

每个可导航页面至少呈现以下状态之一：

1. 正常内容。
2. 明确的加载状态。
3. 带下一步动作的空状态。
4. 带重试入口的错误状态。
5. 无权限说明和返回工作台入口。

应用路由无法识别时显示“页面不存在”，提供“返回工作台”；页面渲染异常时显示“页面暂时无法显示”，提供“重新加载”和“返回工作台”。兜底页不得泄露错误堆栈或敏感信息。

## 视觉和无障碍

- 保留原生 `select`，兼容 macOS、Windows 和键盘操作。
- 层级通过缩进和 `└` 同时表达，不只依赖颜色。
- 完整路径作为辅助文字展示，使用现有表单说明文字样式。
- 空状态和错误状态复用现有色彩、间距、按钮规范，不新增设计依赖。

## 测试与验收

1. 分类数据含“产品资料 → WDSP”时，两个上传入口都显示一级 `产品资料` 和缩进的二级 `└ WDSP`。
2. 选择 `WDSP` 后，提交值仍为 `WDSP`，并显示路径 `产品资料 / WDSP`。
3. 停用分类不出现在上传下拉框。
4. 没有可用分类时，界面给出创建或启用分类的说明，不能无提示提交。
5. 未知页面显示可返回工作台的兜底界面。
6. 页面渲染异常显示可恢复界面，且不展示错误堆栈。
7. 相关前端测试、类型检查和生产构建通过。
