# 聚信 AI 助手 5.9.0 发布说明

发布日期：2026-07-26
发布分支：`codex/ai-assistant-5.0`
发布标签：`ai-assistant-v5.9.0`

## 发布定位

5.9.0 是面向日常使用体验的功能优化版。用户只需描述问题或目标，系统负责识别任务类型、选择执行路径、组织资料和跟踪长任务；同时补齐项目、知识库、Skill、工作流和运维配置之间的使用闭环。

## 主要变化

- 聊天默认自动路由，补充深度研究、多查询检索、来源引用和置信度表达。
- 长报告、PPT 等任务进入后台处理，统一显示任务进度，完成后全局通知并可直接打开结果。
- 聊天历史和长任务支持稳定分页，避免历史数据增长后一次性加载。
- 项目选择使用可读名称，任务、成果和项目支持站内深链，界面不再暴露内部 UUID。
- Skill 支持真实资料附件和结构化执行参数，完善 Dashi PPT 运行时与产物契约。
- 统一 Agent 状态、工具调用、失败原因、重试和成果契约，减少前后端状态含义不一致。
- 知识库新增健康度、重复文件识别、处理状态、版本历史和版本恢复。
- 工作流支持自然语言周期设置，以及启用、暂停和恢复。
- 企业微信与企业微信客服只在前台控制通道启停；凭据继续保存在服务器环境变量，缺少配置时给出明确提示。

## 兼容性与运维

- 保持现有登录、数据库、模型 Provider 和项目数据结构兼容。
- 企业微信凭据不会写入数据库或返回前端；修改服务器 `.env` 后需要重启 API。
- Dashi PPT 仍需在 API 容器中挂载运行时目录和依赖，缺失时返回可诊断错误，不伪造下载产物。
- 新增列表接口保留默认第一页行为，旧客户端无需立即升级。
