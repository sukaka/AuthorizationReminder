# 聚信 AI 助手 5.18.0 发布说明

发布日期：2026-09-21
发布分支：`codex/ai-assistant-5.0`

## 发布定位

5.18.0 是客服系统接入的功能优化版，为第三方客服平台提供默认关闭、可审计且具备安全降级能力的聚信助手问答 API。

## 用户可见变化

- 新增客服消息提交和处理结果查询接口。
- 对接方使用独立 HMAC-SHA256 凭据签名请求，并受时间窗口约束。
- 回答仅使用已审核且允许外部公开的正式知识；没有可靠依据或回答不安全时自动转人工。
- 相同外部消息支持持久化幂等重放，避免客服系统重试造成重复处理。

## 安全与数据保护

- 接口默认关闭，凭据仅通过部署环境变量注入。
- 客户、会话和消息标识仅保存带密钥摘要。
- 客户问题与生成回答均加密落库。
- 外部调用不会获得通用 Agent 工具权限。

## 兼容性与运维

- 新增 Alembic 迁移 `0072_external_answer_cipher`。
- 修正 `0068`–`0070` 迁移在 SQLite 本地回放时的列类型变更兼容性。
- HTTPS Compose 覆盖文件新增客服 API 配置透传。
- 接入方需按 `docs/customer-service-api.md` 配置签名凭据后显式启用。

## 验证范围

- 客服 API 鉴权、签名篡改、知识边界、转人工和幂等测试。
- 外部回答安全链路回归测试。
- Alembic 单 head 检查与升级/降级回放。
- Agent Harness 发布门禁、版本同步和 Git 差异检查。
