# 聚信 AI 助手 3.0.0 发布说明

发布日期：2026-07-15
发布分支：`codex/ai-assistant-3.0`
发布标签：`ai-assistant-v3.0.0`

## 发布定位

3.0.0 是建立在 2.0“个人工作助理＋项目工作空间”之上的专业交付版。统一登录、既有数据库和 BYOM 能力保持不变，新增从专业任务执行到正式成果交付的可审计闭环。

## 主要变化

- 新增专业任务中心和三栏成果工作台。
- 新增 7 个内置 Skill、7 个内置 Template、49 条固定版本质量规则和 2 个审批流。
- 新增不可变成果版本、版本历史、结构化差异和精确版本 Word 导出。
- 新增事实与证据链、人工确认、确定性计算、来源失效和替代证据机制。
- 新增七层质量复核、版本级批注、退回、批准、交付和归档。
- ProfessionalSkillRunner 复用既有 AgentRun，支持九阶段执行、等待输入、恢复和取消。
- 新增交付后去标识化经验候选，不把敏感正文写入审计。

## 升级说明

1. 在 2.0 数据库上执行 Alembic 升级到 `0051_professional_delivery`。
2. 运行 `server/scripts/seed_professional_catalog.py` 初始化内置目录；脚本可安全重放。
3. 运行 `server/scripts/backfill_professional_delivery.py` 为历史成果建立 3.0 映射；脚本可安全重放。
4. 保持现有统一登录、数据库连接、内容加密和 BYOM 配置，不需要迁移到新的身份或模型体系。

## 兼容性与回滚

- 已验证 MySQL 8.4.8 全新安装与 2.0 原地升级。
- 历史成果 UUID、版本、标题、摘要和正文保持不变。
- 可降级 0051；降级删除 3.0 新结构，但保留 2.0 历史成果和版本。
- 已验证降级后再次升级、重新初始化目录和重新回填。
