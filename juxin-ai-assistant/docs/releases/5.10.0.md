# 聚信 AI 助手 5.10.0 发布说明

发布日期：2026-07-26
发布分支：`codex/ai-assistant-5.0`
发布标签：`ai-assistant-v5.10.0`

## 发布定位

5.10.0 是面向普通使用者的体验与稳定性优化版。重点不是增加更多需要用户理解的开关，而是让用户只需提出问题或上传资料，系统自动完成路由、后台执行、进度恢复、完成提醒和成果交付。

## 用户可见变化

- 聊天、任务支持服务端搜索和稳定分页，历史数据增长后仍可快速定位。
- PPT、长报告等后台任务使用持久化完成/失败提醒；刷新或重新登录后提醒仍存在，确认后不重复出现。
- 任务进度继续只保留一处展示，不再新增重复的悬浮进度框。
- 会话、任务、成果和成果版本均可通过 URL 恢复；成果链接能准确打开指定版本。
- 管理员、部门经理和审计员按职责显示治理、部门数据、反馈和审计入口。
- 320、375、768 像素宽度完成响应式适配，核心操作不因窄屏隐藏。
- 普通用户无需手工输入内部 UUID，资料、项目、成果和任务使用可读选择与链接。

## 稳定性与成果交付

- 长任务终态通知使用持久化 outbox 和唯一键，重复执行不会产生重复提醒。
- 100 次 Checkpoint 恢复演练全部成功，重复外部副作用为 0。
- 直连副作用对账覆盖成功重放、幂等键冲突、未知结果、过期执行和失败重试，5/5 通过。
- Runtime shadow 契约比对 150 条，状态差异为 0。
- 新增 Dashi PPT 真实验收工具，实际生成并检查完整 HTML 工程包、PPTX、PDF 和 Word：
  - HTML ZIP 包含 `index.html`、主题运行时和字体等 207 个文件；
  - PPTX、PDF 均为 5 页，Word 可由标准解析器读取；
  - Dashi 官方两项校验通过；
  - 离线浏览器逐页检查 5/5 通过，最后一页正常，无“渲染失败”或空白页。
