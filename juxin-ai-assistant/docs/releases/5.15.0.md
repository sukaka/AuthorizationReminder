# 聚信 AI 助手 5.15.0 发布说明

发布日期：2026-07-27
发布分支：`codex/ai-assistant-5.0`

## 发布定位

5.15.0 是任务失败恢复交互的功能优化版，重点改善任务详情底部操作区的布局、操作层级与窄栏适配。

## 用户可见变化

- 修复任务详情底部按钮被纵向拉伸成高窄胶囊的问题。
- “重新运行”作为失败恢复的主操作突出显示。
- “继续普通回答”作为次操作，保留绕过失败任务继续对话的能力。
- “任务中心”改为轻量入口，减少与主要恢复操作的视觉竞争。
- 窄栏空间不足时按钮自动换行，避免文字挤压和点击区域变形。

## 兼容性

- 不修改原有任务状态、回调行为和后端接口。
- “任务中心”界面显示采用短文案，同时保留“打开任务中心”的无障碍名称。

## 验证范围

- 任务操作区组件交互测试。
- 布局、按钮层级和响应式样式契约测试。
- TypeScript 类型检查。
- 桌面端前端全量测试。
- 版本同步、发布门禁与 Git 差异检查。
