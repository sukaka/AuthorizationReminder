# 聚信 AI 助手 6.0 / 7.0 用户手册（精简）

面向日常使用员工与业务管理员。技术运维见 `ops-runbook-6.0-7.0.md`。

---

## 1. 我该从哪进？

| 我想… | 点哪里 |
|---|---|
| 日常问答 / 写材料 | **聊天** |
| 看任务进度、取消、重试 | **任务中心** |
| 下载报告 / 再编辑成果 | **工作成果** |
| 跑固定业务能力 | **能力中心** |
| 串并行调用多个 Agent | **工作流** |
| 试调 Kimi / 即梦 / 本地 Agent | **Agent 市场** |
| 提交可沉淀的知识点 | **学习中心** |
| 管理员看质量与灰度 | **治理中心 → 运营看板** |

---

## 2. 任务中心（6.0）

1. 打开 **任务中心**，可从聊天跳转或新建任务。
2. 详情里可看：**步骤时间线、引用、自检结果、反馈**。
3. 失败任务可 **重试**（会从上次安全 checkpoint 续跑，尽量不重做已完成步骤）。
4. 有成果时点 **打开成果** 进入工作成果页。

**注意**：生成内容需人工复核后再外发。

---

## 3. 工作成果

1. **工作成果** 分聊天成果 / 任务成果。
2. 支持多格式导出（Word / Markdown 等，以页面按钮为准）。
3. 引用可点 **预览** 看原文片段。
4. 可从成果 **查看来源任务**。

---

## 4. 工作流（7.0）

1. 打开 **工作流**，选择预置流程（如串行、并行、Kimi+即梦）。
2. 填写输入 → **运行工作流**。
3. 运行后可用 **在任务中心打开** 查看审计。
4. **拖拽编排**：增删步骤、拖动排序后保存为自定义流程。

涉及外部 Agent 时，若提示敏感/出域，需勾选确认后再跑。

---

## 5. Agent 市场（7.0）

1. 列表显示本地（echo/summary）与外部（Kimi、即梦等）。
2. 点 Agent 查看 **健康 / 熔断**。
3. **试调调用** 可快速验证；外部调用可能要求出域确认。
4. 管理员可 **授权 / 停用** 市场连接。

未配置厂商密钥时，Kimi/即梦为 **dry-run**（占位结果），仍可用于流程联调。

---

## 6. 学习中心

1. 任务中的优质问答可进入 **学习候选**。
2. 用户可查看自己的候选；**发布必须管理员审核**。
3. 系统禁止「学习自动发布」进入生产。

---

## 7. 管理员日常

运营看板建议每日看：

- 一键就绪检查
- GA 门禁表
- 安全与特权审计
- Agent Hub 健康
- 按钮：**运行离线评测**、**Checkpoint 恢复套件**
- 灰度：5% → 20% → 50% → 100%

出现高危出域、越权、错发：立即将灰度调到 0% 并停用相关 Agent。

---

## 8. 常见问题

**Q: 任务失败了怎么办？**
A: 在任务中心打开详情 → 重试。系统会尽量从 checkpoint 续跑。

**Q: 为什么外部 Agent 调不通？**
A: 看 Agent 市场健康状态；确认是否需出域确认；生产需配置 `KIMI_API_KEY` / `JIMENG_API_KEY`。

**Q: 浏览器和桌面有何区别？**
A: 浏览器可用工作台与任务；本地模型 Key 仅桌面端保存在本机钥匙串。

**Q: 结果能直接发给客户吗？**
A: 不可以。必须人工复核；高风险外发需审核。
