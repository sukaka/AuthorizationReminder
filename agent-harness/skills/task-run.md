# Task Run Skill

## 适用场景

需要按聚信任务流程生成文档、方案、纪要、测试内容、交付材料或整改建议。

## 输入

- 任务类型。
- 用户填写信息。
- 当前助手模式。
- 相关知识来源。
- 文档格式要求。

## 输出

- 结构化任务结果。
- 执行步骤摘要。
- 风险提醒。
- 需确认事项。
- 可导出内容。

## 验收标准

- 输出符合聚信统一文档结构。
- 信息不足时写“待确认”或“根据当前信息，建议进一步确认”。
- 涉及高风险领域时标注“需人工复核”。

## 禁止事项

- 不编造客户、价格、合同、测试结论、验收结论。
- 不输出攻击性代码、绕过、防护规避、日志删除等恶意内容。
