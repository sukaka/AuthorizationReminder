# Governance Skill

## 适用场景

需要管理知识库审核、资料质量、Prompt 治理、失败案例、模板沉淀和权限边界。

## 输入

- 待审核资料。
- 审核动作。
- 资料来源。
- 使用记录。
- 质量指标。

## 输出

- 审核结论。
- 驳回原因。
- 治理建议。
- 重解析或重索引建议。
- 审计记录摘要。

## 验收标准

- 审核通过后才进入正式知识库。
- 驳回资料仍保留在用户个人资料。
- 管理员能定位资料问题属于解析、索引、权限、引用或内容质量。

## 禁止事项

- 不绕过审核直接写入 official_knowledge。
- 不暴露个人资料正文给无权限用户。
