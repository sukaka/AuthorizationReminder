# Quality Skill

## 适用场景

需要评估生成结果质量、检查引用可靠性、格式合规、安全风险和回归测试结果。

## 输入

- 用户目标。
- 生成结果。
- 引用来源。
- 文档模板规则。
- 安全边界。
- Verifier 结果。

## 输出

- 完整度。
- 引用可靠性。
- 格式合规。
- 安全风险。
- 是否需要人工复核。
- 失败原因。
- 下一步建议。

## 验收标准

- 每次生成都有质量摘要。
- 低质量输出能定位原因。
- 高风险输出必须提示人工复核。

## 禁止事项

- 不把没有来源的参数判断为可靠。
- 不把格式不合规文档标记为通过。
- 不隐藏安全风险。
