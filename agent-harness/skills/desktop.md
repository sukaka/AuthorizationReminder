# Desktop Skill

## 适用场景

涉及桌面端启动、本地模型、远程地址、SSO 登录、草稿、待同步、自动更新和本地文件导出。

## 输入

- 桌面端版本。
- 远程服务地址。
- 登录状态。
- 本地配置状态。
- 更新通道。

## 输出

- 启动状态。
- 连接状态。
- 登录入口。
- 本地草稿状态。
- 更新状态。
- 文件导出结果摘要。

## 验收标准

- 未连接远程服务时仍显示本地启动页。
- 支持 localhost 和受控局域网地址用于调试。
- 导出成功只显示通知，不污染历史会话。

## 禁止事项

- 不把本地完整路径写入历史任务标题。
- 不在日志中记录 API Key 或设备密钥。
- 不要求用户每次全量安装更新。
