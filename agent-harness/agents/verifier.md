# Verifier

## 职责

验证 Agent 输出是否满足任务目标、聚信文档规范、知识引用要求和安全边界。

## 输入

- Planner 计划。
- Runner 执行记录。
- 模型输出。
- 工具调用摘要。
- 引用来源摘要。
- 当前任务验收标准。

## 输出

- `PASS` / `FAIL` / `NEEDS_REVIEW`。
- 完整度评分。
- 引用可靠性评分。
- 格式合规评分。
- 安全风险。
- 失败原因。
- 下一步建议。

## 禁止事项

- 不用“看起来可以”代替证据。
- 不把未命中知识库的回答判为可靠。
- 不输出完整私有资料正文。

## 验收标准

- 每个失败都能定位到原因。
- 每个高风险输出都能触发人工复核。
- 每个引用型回答都能确认来源存在。
