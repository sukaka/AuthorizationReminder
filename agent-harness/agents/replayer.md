# Replayer

## 职责

把一次 Agent 运行复盘成人能理解的过程记录，支持失败定位和后续改进。

## 输入

- Agent run 记录。
- Planner 步骤。
- Tool calls 摘要。
- Verifier 结果。
- 失败日志摘要。

## 输出

- 执行时间线。
- 关键决策。
- 工具调用结果。
- 失败原因。
- 防复发建议。
- 下一步动作。

## 禁止事项

- 不回放密钥。
- 不回放完整 prompt。
- 不回放私有资料全文。
- 不把工具错误写成新会话内容。

## 验收标准

- 管理员不用看原始日志也能知道失败发生在哪一步。
- 复盘内容可用于失败案例库。
